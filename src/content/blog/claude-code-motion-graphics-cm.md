「会社紹介の動画を作りたい。でも編集ソフトは触れないし、外注するほどの予算もすぐには出せない」。そう感じている中小企業の方に向けて、私が実際に30秒の企業CMを作った手順を全部書きます。

結論から言うと、編集ソフトを一度も開かずに、Claude Code（Claudeのデスクトップアプリで使える、パソコンの中で作業してくれるAI）へ頼むことで、CMの動き・文字・つなぎまで作れました。ただし写真と2カットの映像、曲、ナレーションの声は、AIで生成した素材です。Claudeの有料プランに加えて、生成の費用も数百円かかっています。

10月30日に公開したYouTube動画の内容を、料金と規約を11月2日に公式ページで確かめ直して書き直しました。実際に使った頼み方を、自社に置き換えられる形に整えたプロンプト（AIへの依頼文）を全文載せています。

## この記事の要点

- 編集ソフトは開いていません。動きと文字はClaude Codeと、無料の道具HyperFrames（ハイパーフレームズ）で作りました
- 写真20枚・映像2本・曲・声はAIで生成した素材です。生成の実費は声の候補選びまで含めて約560円以内でした（Claudeの料金は別）
- 流れは「環境を作る→素材→構成案→作って検品→曲と声」です。環境づくりは最初の1回だけです
- 仕上がりに効いたのは3つ。「After Effects」という言葉を入れること、エフォートレベルを最大にすること、AI自身に検品させることです

## 動画の補足：正確にはこうです

動画の中では「動画生成AIも使っていません」「必要だったのは Claude の有料プランだけです」と話しています。正確には次のとおりです。

1点目。CMの中のタワー（4.9〜6.3秒ごろ）とセミナー（16.0〜17.4秒ごろ）は、動画生成AIで作った映像です。編集ソフトを開いていないこと、動きと文字とつなぎをClaudeが作ったことは、話したとおりです。

2点目。曲と声には Gemini の APIキー（外のAIを使うための鍵）が要り、使った分だけ支払いがあります。動画の途中で Gemini の APIキーの話はしていますが、冒頭の言い方とは合っていませんでした。写真は別の画像生成AIで作りました。

動画の題名の「Claudeだけで」「全自動」は、動きを作る工程を指した言い方です。実際は、写真と映像2本、曲、声はAIで生成した素材で、構成案を選ぶ、原稿と声を直す、という人の判断が入っています。

実際の内訳はこうなります。

| 作ったもの | 道具 | 実費 |
|---|---|---|
| 動き・文字・3D・つなぎ | Claude Code と HyperFrames | Claudeの料金のみ |
| 写真20枚 | 画像生成AI（GPT Image 2.5） | 約42円 |
| 映像2本（各6秒） | 動画生成AI（Gemini Omni Flash） | 約184円 |
| 曲 | Google の Lyria（リリア） | 3回で約30円（うち1回は0.04ドルの30秒版です） |
| 効果音 | Final Cut Pro に付属の音（編集ソフトは開かず、Claudeがファイルを切り出して配置） | 追加の実費なし（Final Cut Pro を持っている前提） |
| ナレーション | Gemini 3.8 Flash TTS | 1回読ませて約1円 |
| 声の候補選びの全部 | 同上と聞き比べのAI | 約300円以内 |

持っていない方は、プロンプト4-4の「短い音を自分で作ってよい」で頼めます。ただし冒頭のCMの音はこの作り方ではありません。

実費は1ドル150円で換算した、10月28〜29日の制作の記録です。これとは別に Claude の有料プランがかかります。日本の公式料金ページの表示で、Pro は月払い税込み22ドル（年払いなら月18ドル相当、220ドル一括）です。

逆を返せば、自社の写真と映像が手元にあれば、写真と映像の約226円は要りません。曲を自分で用意するなら、Gemini の APIキーは声を作るときだけで済みます。

## 前提知識：HyperFrames と Remotion の使い分け

Claude Code がグラフィックを作る方法で有名なものは2つあります。HyperFrames（HeyGen社が公開している無料の道具）と Remotion（リモーション）です。

たとえるなら、HyperFrames は1点ものを作り込む職人さん、Remotion は同じ型で何本も作る工場です。今回のようなCMは HyperFrames、YouTube の編集の繰り返しや、同じエフェクトを何度も使うときは Remotion が向いています。

| | HyperFrames | Remotion |
|---|---|---|
| 向いているもの | 1本を作り込む（会社のPR） | 同じ型を繰り返す（YouTube編集） |
| 作り | ホームページと同じ仕組み（HTML） | プログラムの部品（React） |
| お金 | 会社の規模を問わず無料・商用可 | 3人までの会社は無料。4人以上は有料 |

Remotion の料金は確認が要るので、11月2日に公式で確かめた内容を書いておきます。

- 無料：個人と、3人までの会社。4人以上の営利の会社は会社ライセンスが必要です
- 会社ライセンス：制作者向けは1席 月25ドルから（AIに書かせる場合も含めて、コードを書く人1人ごと）。自動化向けは1回0.01ドル、月100ドルからです
- 人数の数え方：同じプロジェクトを一緒に動かす業務委託の人や他社の人も、公式のよくある質問では合算すると書かれています。一方で、完成したMP4だけを納品する相手の人数は数えません

「うちは社員3人だから無料」と決める前に、公式の [License FAQ](https://www.remotion.dev/docs/license/faq) を一度読んでみてください。今回のCMだけなら Remotion は使いません。4人以上の会社は外して大丈夫です。

![HyperFramesとRemotionの使い分け。HyperFramesは1本を作り込む、Remotionは同じ型を繰り返す](/blog/claude-code-motion-graphics-cm/diagram-3-hyperframes-remotion.webp)

## 準備1：環境は「入れて」と頼むだけ

必要なものは次のとおりです。

| 必要なもの | 中身 | 費用 |
|---|---|---|
| Claude の有料プラン | Pro 以上。無料プランでは Claude Code は使えません | 月払い 税込み22ドル |
| パソコン | Mac でも Windows でも。動画は Mac です | 手持ち |
| 動画制作の5点セット | HyperFrames、Remotion、FFmpeg（動画を切ってつなぐ道具）、日本語の書体、文字起こし | 無料（Remotion は上の条件） |
| Gemini の APIキー | 曲と声をAIに作らせるときだけ | 使った分だけ（新規は最低5ドルの前払いから） |

準備は3つです。

1. デスクトップに「PR動画」という空のフォルダを作ります
2. Claude のデスクトップアプリの「Code」タブで、そのフォルダを開きます
3. 下のプロンプトを貼って送ります

AIがパソコンの中を確かめて、足りない道具を入れてくれます。パスワードが要る所だけ、自分で打って進めます。

プロンプト1：環境を作る（1回だけ）

> このパソコンで、Claude Code でモーショングラフィックスの動画が作れるように、必要な道具をセットアップしてください。
>
> ・入れるもの（Claude の動画制作の5点セット）：HyperFrames（モーショングラフィックスを動画にする）、Remotion（同じ型の動画をデータから量産する）、FFmpeg（動画を切る・つなぐ）、日本語の書体 Noto Sans JP（文字が文字化けしないための設定）、文字起こしの道具（このパソコンで動く Whisper など）。動かすのに必要なもの（Node.js など）も一緒に
>
> ・Remotion は4人以上の会社で使うと有料なので、入れる前にそのことも教えてください
>
> ・このフォルダの中に、HyperFrames のプロジェクト（名前は【company-pr】）を作ってください。スキル（HyperFrames の説明書）は、company-pr の中だけに入れて、パソコン全体には入れないでください。プロジェクトの中に、材料を入れる空のフォルダ（assets/photos・assets/video・assets/logo・assets/bgm）と、「会社の事実.md」のひな形（社名・場所・何をしている会社か・キャッチコピー、の見出しだけ）、「素材の記録.md」のひな形（写真や映像ごとに「ファイル名・何が写っているか・横か縦か」を書く表）を作り、日本語の書体のファイルは assets/fonts に置いてください
>
> ・HyperFrames の利用状況の送信（テレメトリー）は止めてください。publish（共有リンク）は使いません
>
> ・私はパソコンに詳しくありません。何を入れるのか、なぜ必要なのかを、中学生にも分かる言葉で先に説明してから進めてください
>
> ・管理者パスワードが必要な操作や、パソコンの設定を変える操作は、勝手に進めずに止まって、私がやることを教えてください
>
> ・最後に、ちゃんと入ったかを確認して、結果を教えてください。次の会話でどのフォルダを開けばよいかも教えてください

終わると、フォルダの中はこうなります。

```
PR動画
└── company-pr
    ├── 会社の事実.md
    ├── 素材の記録.md
    ├── SPEC.md
    └── assets
        ├── photos
        ├── video
        ├── logo
        ├── bgm
        └── fonts
```

「会社の事実.md」は会社のことを書く文章です。動画にはここに書いたことだけを使わせます。「素材の記録.md」は写真ごとに何が写っているかを書く表です。SPEC.md は、あとのプロンプト4-2で作ります。

プロンプト3からは、company-pr を開いた新しい会話で送ります。「/hyperframes が使えない」と言われたら、会話を開き直してください。

細かい画面は [前回の動画「AI動画編集の完全攻略」](https://www.youtube.com/watch?v=49OIGpNKVhA) で解説しています。補足を3つ書いておきます。

- 「skills update を実行して」と出ることがありますが、無視して大丈夫です。実行すると道具の説明書がパソコン全体に入ります
- 初めての書き出しだけ、書き出し用のブラウザ（約190MB）を取ってくるので長くなります
- 公式のプラグインで入れた場合、呼び出しの言葉は `/hyperframes` ではなく `/hyperframes:hyperframes` になります

## 準備2：Gemini の APIキーをつなぐ

曲とナレーションも AI で作るなら、Gemini の APIキーが必要です。流れは、Google AI Studio でキーを作り、環境変数という場所に入れて、Claude Code につなぐ、というところです。

環境変数は、パソコンの中の「鍵の保管場所」です。キーそのものをチャットに貼らず、Claude Code には鍵の名前だけで呼んでもらいます。

![環境変数はパソコンの中の鍵の保管場所。APIキーをGEMINI_API_KEYという名前で入れて、Claude Codeが名前で呼んで使う](/blog/claude-code-motion-graphics-cm/diagram-5-env-var.webp)

プロンプト2：Gemini の APIキーをつなぐ（1回だけ）

> 曲（Google の Lyria）とナレーション（Gemini の読み上げ）をあなたに作ってもらいたいので、Gemini の APIキーを使えるようにします。
>
> APIキーは、このチャットには貼りません。
>
> 1. Google AI Studio（aistudio.google.com）で「Get API key」からキーを作る手順を、画面の言葉で1つずつ教えてください
>
> 2. 作ったキーを、私のパソコンの「環境変数」（GEMINI_API_KEY）に安全に入れて、あなたが使えるようにする手順を、1つずつ教えてください。入れるのは、私が自分のターミナルでやります
>
> 3. 入れ終わったら、キーの中身は表示せずに、つながったかだけ確かめてください（いちばん安い方法で）

ここで注意点が2つあります。

1点目。会社の素材を扱うなら、キーは有料の設定（請求先の登録）にしてください。公式の規約では、無料枠で入れた内容と生成結果は Google の製品改良に使われ、人が読むこともあるとされています。有料の設定なら改良には使われません。不正利用を見つけるために、一定期間は記録されます。

2点目。曲を作る Lyria は、11月2日時点の料金ページで無料枠がありません。なので曲を作るなら、どのみち請求先の登録が要ります。料金は1曲0.08ドルです。新しく登録する場合、公式の案内では最低5ドル（約750円）の前払いから始まるのが基本です。使わなかった分は12か月で失効し、原則返金されません。なので、実費が数百円でも、最初の支払いは約750円と考えておいてください。

## STEP2：いきなり作らせず、まず構成案

素材ができたら、作らせる前に構成案を出してもらいます。動画の画面で見せた依頼文はこれです。

> ソラガタ不動産の、30秒のPR動画を作ります。
>
> 本物のテレビCMのような、ハイクオリティな動画にしてください。
>
> 素材は「素材」フォルダと「制作プロジェクト」にあります。
>
> 会社のことは「会社の事実.md」だけを使ってください。
>
> HyperFramesで、After Effectsじゃないと作れないようなモーショングラフィックスを。
>
> 写真に頼りすぎず、線や図形、3D、光の点の場面を織り交ぜて、テンプレ感をなくしてください。
>
> イメージはお任せします。横1920×1080・30fps・30秒です。
>
> まだ作らずに、まず構成案をください。

中身を分解すると、5つです。

1. ゴール：何の動画を、誰に、何秒で。実物の動画やスクリーンショットがあれば、見せるのが一番です
2. 情報の場所：素材はフォルダの中を見るように指示します
3. 道具の名前：HyperFrames と書きます。道具の名前がないと、別の作り方で作ってしまうことがあります
4. 質の指定：「After Effects」という単語です。入れるとテンプレ感がなくなり、クオリティが上がりやすかったです
5. 止める指示：「まだ作らずに、まず構成案を」。いくつか案が出てくるので、AIと相談して決めます

正直なところ、私も最初の1本は写真に頼りすぎて、テンプレっぽい仕上がりでした。「写真に頼りすぎず、線や図形、3D、光の点で」の一言は、その直しから来ています。

### 頼む前に、エフォートレベルを最大にする

エフォートレベルは、AIがどれだけ深く考えるかの設定です。入力欄の下で変えられます。公式の説明書によると、Opus 5.5 の既定は「medium（中）」なので、何も触らないと中くらいのまま動きます。

上げると、作る時間と使用量はかかります。ただ、モーショングラフィックスはエフォートレベルが低いとクオリティも低くなってしまいます。なので、ここは最大にします。最大はその会話だけの設定なので、新しい会話を開くたびに上げ直してください。Pro で出ない場合は、選べるいちばん上で大丈夫です。

![エフォート最大でクオリティが一気に上がる](/blog/claude-code-motion-graphics-cm/diagram-7-effort-max.webp)

>
> ・作ったら書き出して、0.25秒ごとのコマの一覧（30秒なら120枚）を作り、自分の目で厳しく検品してください（文字の切れ・重なり・スマホで読めない小さな文字・黒い画面だけの間・つなぎ目の明るさの跳び・動きの止まり）。見つけたら直して、合格するまで2回以上作り直してから見せてください

架空の会社で作るなら、「隅に小さく『※この動画の会社・物件・人物は架空です』」の1行を足してください。写真がなければ、「写真は使わず、文字と図形と3Dと光だけで」に替えます。映像や曲がなければ、その部分を消して「音は短い効果音だけ。外のサービスから探してこない」に替えます。結果は毎回変わるので、同じ動画ができるわけではありません。

冒頭のCMはプロンプト4の作り方で作りました。プロンプト3はそれを1つの会話にまとめた版で、私もまだ通しでは試していません。

## STEP3：作ったら、AI自身に検品させる

構成案が決まったら「この構成で作ってください」と頼みます。そして作った後は、AIに自己採点をさせて、ミスを自分で直させます。

モーショングラフィックスは、タイミングのズレや位置のズレが起こりやすいからです。具体的には、30秒の動画を0.25秒ごとに切った120枚のコマの一覧を作らせ、AIに自分の目で見させます。

![0.25秒ごとに切った120枚のコマの一覧。AI自身がこの一覧を見て検品する](/blog/claude-code-motion-graphics-cm/diagram-8-contact-sheet.webp)

プロンプト5-1：自己検品（作ったあとに、いつでも）

> 書き出した動画を、0.25秒ごとのコマの一覧にして、あなた自身の目で厳しく検品してください。
>
> 見る所：文字の切れ・重なり、スマホで読めない小さな文字や細い文字、黒い画面だけの間、つなぎ目の明るさの跳び、動きが止まって見える所、書いていない数字や注記。
>

自動の点検（check）に合格していても、完成ではありません。冒頭のCMでは、組み立てたあとの一覧をAI自身に見させて、3つの問題を見つけて直しました。

| 見つけた所 | 直したこと | 数値の変化 |
|---|---|---|
| 夜の3Dから昼の写真へのつなぎ目で明るさが跳ぶ | 光で前後をなじませた | コマの差 90.5→44.0 |
| 冒頭0.7秒がほぼ黒い画面に線1本 | 最初のコマから方眼の用紙を出した | 平均の明るさ 16→38 |
| スマホで読めない小さな文字 | 文字を大きく太く | 警告 12→1 |

もう1つ、実在の会社で作るなら大事な話です。動画の収録で検品をやらせたとき、AIは「48棟・5,200件・18,000名は会社の事実.md に書かれていない実績の数字」と指摘しました。AIは絵に合わせて数字を足すことがあります。架空のCMなのでそのまま残しましたが、自社の動画なら消してください。

## 本気の1本：3つの会話で同時に作る

順番は 6-1 →4-1 →4-2 →4-3（3つ）→4-4 →5-1 →5-2 →6-2 です。

動画では「この構成で作らせました」と一言で話しましたが、冒頭のCMは、もう少し手をかけています。30秒を曲の小節で3つに分けて、3つの会話で同時に作り、4つ目の会話で組み立てました。1本を3人のデザイナーに分けて頼むイメージです。

![本気の1本は3つの会話で同時に作る。曲の小節で3つに分け、同じ決まりを渡し、区間ごとに作り、4つ目の会話で組み立てる](/blog/claude-code-motion-graphics-cm/diagram-9-three-chats.webp)

待ち時間は、3つが同時に進むので「いちばん長い区間＋組み立て」です。記録では区間ごとに約55〜70分、組み立て約35分で、合わせて約1時間45分でした。直しに各25分前後と、組み立て直しに約17分が別にかかっています。

先に曲を assets/bgm に入れておきます（曲の作り方は次の章のプロンプト6-1）。

## 直しは「時刻で」頼む

動画生成AIと違って、作り直しをせずに細かい所だけ直せるのがモーショングラフィックスの強みです。理由は、映像の中身がコードだからです。

>
> 3. 【何】秒：【スマホで読めない小さな文字・細い文字】 → 【28px以上・太さ500に／読めないなら消す】

## よくある質問

### Team プランは要りますか

要りません。Pro 以上で Claude Code が使えます。無料プランでは使えません。

### Pro で足りますか

ここは正直、測っていません。私自身は Max プランで作ったので、Pro でどこまで収まるかは分かりません。公式には、Pro は5時間ごとと週ごとの上限があり、チャットと Claude Code で同じ枠を使うと書かれています。エフォート最大は使う量が増えるので、構成案で一度止める、直しはまとめて送る、が節約になります。

### Windows でもできますか

動画は Mac ですが、公式では Claude のデスクトップアプリも HyperFrames も Windows に対応しています。

### Seedance や Kling のような動画生成AIとは何が違いますか

動画生成AIは映像そのものを生成します。今回のやり方は、文字や図形の動きをコードで作ります。実写の人や街はコードでは作れないので、そこは写真や映像の素材が要ります。

### AIで作った曲を会社のサイトで使っても大丈夫ですか

結論から言うと、Gemini API で作った曲は、規約を読むかぎり会社のサイトで使えないとは書かれていません。この記事のデモ動画も、私はこの読み方で音つきで載せています。

Gemini API の追加規約には、生成物について「Google は所有権を主張しない」とあり、音楽に限った条件も11月2日時点で見当たりません。ただし、他の人の権利を侵害しないと保証するものではありません。同じ規約に、似たものが他の人にも生成されうること、使う責任は利用者にあることも書かれています。

Gemini アプリで作った曲には別の規約が適用されます。ここは私の読み方で、法律の判断ではないので、広告など大きく使うなら専門家にも確認してみてください。生成された曲には SynthID という聞こえない透かしが入ります。
