「採用や商品の想いを、短い物語の動画で伝えたい。でも俳優さんを呼んで撮影するのは、うちには無理」。そう感じている中小企業の方に向けて、俳優も撮影もなしで、AIだけで作った2分のドラマを、作品と作り方に絞ってご紹介します。

台本も、映像も、声も、AIで作りました。

結論から言うと、AIだけで台本から2分のドラマは作れました。ただ正直なところ、全自動で完成とまではいきません。台本を練り上げることと、最後に確かめることは人の仕事でした。

## 作り方

### 使った道具と役割

| 役割 | 使ったもの |
|---|---|
| 台本 | Claude（Anthropic のAI） |
| 映像 | Seedance 2.5（Higgsfield から使用） |
| 「僕」の語りの声 | Gemini の音声合成 |
| 台本を練る・道具を選ぶ・最後に確かめる | 私 |

台本は、Claude に書かせました。映像を作るAIは Seedance 2.5 の1つだけです。

私がやったのは、台本を練り上げていくことと、使う道具を決めることです。AIは何でも作れるので、どの台本で何を言うか、どのAIを使うかを人が決める、という役割分担でした。

### 作り方は2つ

Higgsfield には、台本からドラマを作る機能（Short Drama Studio）があります。作り方は、サイトで作る方法と、Claude から作る方法の2つです。

サイトで作る方法は、4つの手順です。

1. 台本を渡す。ショートドラマの画面で「スクリプトをアップロード」に台本のファイルを入れます。Word でもテキストでも大丈夫です。
2. 人物を確かめる。台本を読んだAIが、登場人物と場所の絵を先に作ってくれます。この絵が全部のカットの元になるので、顔と服をしっかり見て、イメージと違えばここで作り直します。
3. 下書きを直す。いきなり本番の画質では作らず、画質の粗い下書きを作って、弱い部分だけ作り直します。
4. 本番にする。下書きに納得できたら、本番の画質に上げて完成です。

Claude から作る方法は、こうです。

1. Higgsfield のサイトの「Claudeに接続」から、Claude とつなぐ
2. ショートドラマ用のスキル（決まった手順をまとめた説明書のようなもの）を Claude に入れる
3. Claude に「ショートドラマを作りたい」と頼むと、どんな話にするか、何話にするか、絵柄はどうするかを質問してくれるので、答えていくと台本が出てくる
4. 「この台本でドラマを作って」と頼むと、画質を聞かれて、クレジット（生成に使うポイント）の見積もりが出る

完成した台本があるならサイト、台本から相談しながら作りたいなら Claude、という使い分けがいいかなと思います。

### 台本のポイント

Claude に渡した台本のコツは1つです。最初にドキッとする一言を置いて、続きが気になるところで終えること。なので今回は「僕は、耳が聞こえない。」という言葉から始まる話にしました。

### かかった時間とクレジット

| | クレジット |
|---|---|
| 下書き | 450 |
| 本番の画質（1080p）に仕上げる | 2,000 |
| 合計 | およそ2,450 |

下書きは10場面作り、2分に収めるために8場面を使いました。時間は、同じ台本をサイトに渡して作り直したときの実測で、台本を渡してから本番の画質の映像がそろうまで約1時間でした。台本を練る時間は、これとは別にかかります。

## ここから分かること：中小企業でも、物語の動画が作れるようになった

### 1. 人の仕事は「何を語るか」を決めること

俳優を探す、場所を借りる、撮影するといった手間がなくなり、人の仕事は台本を練ることと、最後に確かめることに絞られます。逆を返せば、伝えたい中身さえあれば、物語の動画が作れるということです。

### 2. 向いている仕事

- 採用動画で、社員の1日や入社した理由を短い物語にする
- 商品が生まれたきっかけや、創業の想いを伝える
- SNSで流す1〜2分のドラマ

実は、こういう1〜2分のドラマは、いま世界で伸びている分野です。

### 3. 作ってみて分かった3つのコツ

1つ目は、カットを短く刻むことです。動画生成AIは、1カットが長いと顔が崩れやすくなります。今回は1カットを長くても3秒半ほどにしたので、28秒の長い場面でも、顔は最後まで同じでした。

2つ目は、写したくないものは、あえて書かないことです。「パソコンの画面は映さない」と書いたら、逆にパソコンが映ってしまいました。AIは、書かれた言葉を絵にしてしまうんですよね。プリンの瓶では、「無地の瓶」と頼んだら、瓶に「PLAIN」（無地の英語）という文字が出ました。写したくないものは、名前を出さずに指示を書くのがコツです。

3つ目は、下書きを決めてから本番にすることです。下書きは、本番の5分の1ほどのクレジットで作れます。しかも本番は、下書きと同じ動きのまま画質だけが上がります。なので、直すのは必ず下書きのうちに、と覚えておいてください。

### 4. まだ苦手なこと

1つ目は長さです。「2分以内」と指定したのに、最初は2分半ほどの作品ができました。そこで、10場面のうち2場面を外して、2分に収めています。外した場面には、さっきの「PLAIN」の瓶や、頼んでもいないスマホが手前に映った場面もありました。

2つ目は細かい直しです。14秒あたりの瞬きが少し不自然だったので、そこだけ直せないか試しましたが、自然には直りませんでした。最後は、生成されたままの絵を使っています。動きと音は、最後に自分の目と耳で確かめる必要があります。

### 5. どこから始めるか

まずは、自社の採用や商品にまつわる1分の話を、Claude と一緒に台本にしてみてください。1行目を「続きが気になる一言」にするだけで、ぐっと見てもらいやすくなるかなと思います。
