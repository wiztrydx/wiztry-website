朝パソコンを開くと、返事が止まっている問い合わせが古い順に並んでいて、返信の下書きまで置いてある。社長は読んで、直して、送るかどうかを決める。

これは Claude Code（クロードコード）のスケジュール機能で作れます。時間を決めて、AIに仕事を始めてもらう機能です。プログラムは書きません。日本語で頼みます。

ただし、何もかも任せられるわけではありません。パソコンとアプリが起きている必要がありますし、送る・公開する・消す・お金を払うは、人が決める所です。この記事では、そこも含めて、最初の1体を安全に作る手順を説明します。

この記事は、11月20日に公開した YouTube 動画の内容を、初めての方が練習用のデータで再現できる手順に組み直したものです。機能の説明は、11月22日に公式のページで確かめ直しました。

## この記事の要点

- AIエージェントは「教えてくれるAI」ではなく「やってくれるAI」です。人は最初のお願いと最後の確認をします
- 一番シンプルな作り方は、Claude の有料プランとパソコン用アプリです。5行で頼んで「今すぐ実行」で確かめます
- 今回の作り方で動くのは、パソコンが起きていて、アプリが開いている間だけです。ふたを閉じると止まります
- 「送信はしないで」と書くだけでは足りません。送信・公開・削除は、設定でも止めます

## AIエージェントとは「やってくれるAI」

まず、言葉を1つだけ押さえます。

これまでのAIは「教えてくれるAI」でした。やり方は教えてくれますが、手を動かすのは人です。

AIエージェントは「やってくれるAI」です。ファイルを開いて、読んで、作って、保存します。考えて、手を動かして、確かめる。これを出来上がるまで繰り返します。人がやるのは、最初のお願いと最後の確認です。

![AIとAIエージェントの違い。これまでのAIは教えてくれる、手を動かすのは人。AIエージェントはやってくれる](/blog/claude-code-neteruma-ai-shain/diagram-1-agent.webp)

たとえば、返事が止まっている問い合わせを探す場面で比べると、こうなります。

| 場面 | 教えてくれるAI | やってくれるAI |
|---|---|---|
| 頼むと | 探し方を説明する | フォルダを読んで探す |
| できる物 | 手順の文章 | 一覧と返信の下書き |
| 人の仕事 | 探す・書く・送る | 確かめる・送る |

Claude Code は、やってくれるAIの代表的な道具です。名前に Code と付いていますが、Claude のパソコン用アプリの「Code」のタブから、日本語で使えます。

## 弊社では、こう働いてもらっています

動画では、よく働いているAI社員を4つのグループに分けて紹介しました。

1. 事務：メールの下書き、日程の調整、議事録
2. 連絡：返事がいる連絡の整理、お知らせの下書き
3. 調べ物と見回り：補助金の情報、運用しているシステムの点検
4. 作る仕事と発信：資料、動画の台本、ブログやSNSの下書き

決まった時刻に動いている物もあれば、頼んだときに動かしている物もあります。全部が勝手に動いているわけではありません。

私の1日は、朝に届く1枚のメモを読むところから始まります。書いてあるのは、今日の予定、送るのを待っている下書き、返事が止まっているメールの3つです。なので朝いちばんに「今日は何から手を付けるか」を探さなくて済みます。

### うまく働かせるコツは、道具とノウハウを渡すこと

AIエージェントは、手ぶらでは働けません。人の社員と同じです。渡す物は2種類あります。

1. 道具：仕事に必要なファイルや、使っているサービスへのつなぎ口
2. ノウハウ：テンプレートと、会社の決まり事

正直なところ、会社の決まりは私の頭の中にしかない物が多くありました。それをAIが読める形に書き出して渡しています。ただ「資料を作って」と頼むと、どこかで見たような資料が返ってきます。逆を返せば、型と決まりを渡すほど、自社の仕事に近づくということです。

AI社員が集まった会社全体の作り方は[AI社員の作り方](/blog/ai-shain-tsukurikata/)、働いている様子を見える化する話は[AIオフィスの作り方](/blog/ai-office-tsukurikata/)に書いています。この記事は、その手前の「時間で動く仕事を1つ作る」に絞ります。

## 最初に任せる仕事の選び方

動画で紹介した目安は3つです。

1. 毎週、繰り返している
2. 型やテンプレートがある
3. 自分ではやりたくない

このうち2つ以上当てはまったら、AIに任せる候補です。

![任せる仕事を選ぶ3つの目安。毎週繰り返している、型やテンプレートがある、自分ではやりたくない。2つ以上ならAIに任せる](/blog/claude-code-neteruma-ai-shain/diagram-2-choose.webp)

中小企業でよくある仕事に当てはめると、こう分かれます。

| 最初の1体に向く | まだ人が持つ |
|---|---|
| 返事が止まっている問い合わせの一覧 | お客様への送信 |
| いつもの型の返信の下書き | 値引きや契約の判断 |
| 会議のメモからやることの一覧 | 支払いと金額の確定 |
| 決まった公式ページの更新の確認 | 社外への公開 |

今回は「返事が止まっている問い合わせを見つけて、返信の下書きを作る」を例にします。

## AI社員の1体目を作る手順

動画では、作り方を4つに分けて話しました。つなぐ、ノウハウを渡す、AIに質問してもらう、動く時間を決める、です。ここでは初めての方向けに、練習用のフォルダで「動く時間を決める」までを5つの手順にします。

![AI社員の1体目を作る5つの手順。用意する、頼む、動かす、答え合わせ、翌朝見る](/blog/claude-code-neteruma-ai-shain/diagram-3-steps.webp)

始める前に必要な物は2つです。

- Claude の有料プラン（Pro、Max、Ultra、Team、Enterprise）。無料プランでは Claude Code を使えません
- パソコン用の Claude アプリ（Mac・Windows）

### 手順1：練習用のフォルダを作る

いきなり本物のメールにはつなぎません。パソコンに空のフォルダを1つ作り、架空の工務店のデータで練習します。

Gmail などのつなぎ口（コネクタ）をすでに使っている方は、練習の間は外しておいてください。アプリの「Customize（カスタマイズ）」の「Connectors」から切り離せます。自分で足した MCP（外のサービスにつなぐ仕組み）などがあれば、それも外します。

フォルダに入れる物は、次のとおりです。

![練習用のフォルダに入れる物。架空のA様からF様までの問い合わせ6件、送った返信2件、空のフォルダ2つ、会社のメモ、AIが読む決まりのCLAUDE.md](/blog/claude-code-neteruma-ai-shain/folder.webp)

| 入れる物 | 役目 |
|---|---|
| 受信した問い合わせ（6件） | AIが調べる元のデータ |
| 送った返信（2件） | 返事が済んだかどうかの答え |
| 会社のメモ | 返信の書き方 |
| CLAUDE.md | AIが仕事の前に読む決まり |
| 返信の下書き・朝のメモ | できた物の置き場 |

手で作らなくても大丈夫です。アプリの「Code」のタブで空のフォルダを開きます。場所は「Local」を選びます。

送る前に、入力欄の近くにある許可のモードを「Manual（手動）」にしてください。許可のモードは「AIがどこまで聞かずに進めるか」の設定です。それから次の文を送り、書き込みの許可を聞かれたら、中身を見て許可します。動画には無い、この記事用に足した文です。

> このフォルダに、練習用のデータを作ってください。会社は架空の「〇〇工務店」、相手も架空のA様〜F様です。
>
> 1.「受信した問い合わせ」フォルダに1件1ファイルで6件。A様 キッチン（今日の11日前）、B様 外壁（9日前）、C様 トイレ（7日前）、D様 和室（4日前）、E様 手すり（3日前）、F様 雨どい（1日前）。届いた日付も書く。
>
> 2.「送った返信」フォルダに2件。A様とD様への返信。
>
> 3.「会社のメモ」のファイル。返信はていねいに短く、最初にお礼、現地調査の候補日を2つ、金額は書かない。来週の平日から訪問できる日を4つ。
>
> 4.「返信の下書き」と「朝のメモ」の空のフォルダ。
>
> 5.「CLAUDE.md」のファイル。元のファイルは書き換えない・消さない。送信・公開はしない。返信の下書きは「返信の下書き」に、一覧は「朝のメモ」に保存。分からないことは想像で書かない。

日付を「今日の◯日前」で頼むのがポイントです。データを作った日に試せば、それがいつでも、答え合わせが同じになります。

### 手順2：新しい会話で、5行で頼む

同じフォルダで新しい会話を開きます。許可のモードが Manual になっているかをもう一度見てから、次の文を送ります。動画で紹介し、概要欄にも載せている文です。

> 平日の朝7時に、次の仕事をするように、スケジュールして。
>
> 受信した問い合わせのうち、3日以上、返事をしていないものを、古い順に並べて。
>
> 相手と、用件と、何日たっているかを書いて。
>
> それぞれに、会社のメモの書き方で、返信の下書きを作って。送信はしないで。
>
> 調べられなかったときは、0件と書かずに、調べられなかったと、いちばん上に書いて。

![頼む文の5行の役目。いつ動くか、何を見つけるか、何を報告するか、どこで止めるか、失敗を隠さない](/blog/claude-code-neteruma-ai-shain/prompt.webp)

特に効くのは、最後の1行です。「本当に0件だった」と「読めなくて0件だった」は、まったく別の話です。読めなかったときに0件と書かれると、社長は安心して見逃してしまいます。

仕事ができたら、左の「Scheduled」（表示によっては「スケジュール」「ルーティン」）を開いて、3つ確かめます。

1. 平日の朝7時になっているか
2. 練習用のフォルダになっているか
3. このパソコンで動く設定（ローカル）になっているか

3つ目がクラウドになっていたら、「今すぐ実行」は押しません。その仕事は削除して、「このパソコンで動くローカルのスケジュールにして」と足して頼み直します。クラウドの仕事は、原則 Auto（ほとんど聞かずに進むモード）で始まり、つないであるコネクタが全部入るからです。

### 手順3：「今すぐ実行」で1回、目の前で動かす

押す前に、仕事の画面の鉛筆の印（Edit）を開いて、許可のモードを Manual にします。仕事のモードは会話のモードと別です。何も選ばなければ Claude Code のふだんの設定で動くので、Manual とは限りません。

| モード | 動き | 使いどころ |
|---|---|---|
| Manual（手動） | 書き込みの前などに聞く | 最初の1回 |
| Accept edits（編集を承認・編集を受け入れる） | フォルダ内の編集は聞かない | 答え合わせに合格したあと |
| Auto（自動） | ほとんど聞かずに進む | 最初は使わない |
| Bypass permissions（許可を飛ばす） | 確認をとばして進む | 使わない |

Manual でも、前に「常に許可」した操作や、許可のルールに入れた操作は、聞かずに通ります。Manual なら送信が必ず止まる、とは考えないでください。

Manual にしたら、朝まで待たずに、仕事の画面で「今すぐ実行（Run now）」を押します。

途中で許可を聞かれたら、中身を読みます。読む、下書きを保存する。この範囲だと分かる物だけ「常に許可」を選びます。選ばないと、次の朝、許可待ちのまま止まることがあります。

送信・公開・削除・支払いには、「常に許可」を押しません。中身が分からない命令（コマンド）も押しません。いったん断って、何をする命令なのかを Claude に聞いてください。

![常に許可の線引き。押してよいのは読む、下書きの保存。押さないのは送信、公開、削除、支払い](/blog/claude-code-neteruma-ai-shain/diagram-4-permission.webp)

1つ注意があります。ファイルの保存で「常に許可」を押すと、その回だけが Accept edits に切り替わります。次の回には残りません。

つまり Manual のままだと、次の朝は保存の前で止まります。なので手順4の答え合わせに合格したら、仕事の許可のモードを Accept edits に変えます。

ただし Accept edits は、フォルダの中なら、書き換え・上書き・削除・移動まで聞かずに通ることがあります。なので、練習用のフォルダか、元が別にある写しのフォルダで使ってください。

### 手順4：答え合わせをする

準備の文で作ったデータなら、その日の正解は決まっています。

![答え合わせの見本。返事が止まっているのはB様、C様、E様の3件。A様とD様は返信済み、F様は昨日届いたので入らない。実際に実行した画面ではなく、5行に沿って組んだ例](/blog/claude-code-neteruma-ai-shain/answer.webp)

| 見る所 | 合格の形 |
|---|---|
| 一覧 | B様・C様・E様の3件が古い順 |
| 入らない物 | A様・D様は返信済み、F様は昨日届いた |
| 下書き | 3通。お礼と候補日が2つ、金額なし |
| 元のファイル | 変わっていない、消えていない |

図は、正解に沿って組んだ見本です。違う結果が出たら、頼む文を長くする前に、会社のメモと日付の書き方を見直してください。どこが違ったかをそのまま伝えれば、Claude に直してもらえます。

合格したら、仕事の画面の鉛筆の印から、許可のモードを Accept edits に変えて保存します。これで、次の朝も保存まで進めます。

### 手順5：翌朝、中を開いて確かめる

次に動くのは、次の平日の朝です。一覧に「成功」と出ていても、頼んだ中身が合っているとは限りません。仕事の履歴（History）からその回を開いて、できた物を見ます。

翌朝からは、次の点も見てください。

- 同じ相手の下書きが二重に増えていないか。増えていたら「同じ相手の下書きがあれば、作り直さない」と足します
- 日がたつと、F様も3日以上になって一覧に入ります。練習データを作った2日後からは4件が正解です
- 「平日」は土日をとばすだけです。祝日に止めたいなら、別に頼んでおきます
- 開始は、指定した時刻から数分遅れることがあります

## 自社の仕事に置き換えるときは、AIに質問してもらう

練習がうまくいったら、自社の仕事に置き換えます。このとき、こちらから全部を説明しきろうとしなくて大丈夫です。弊社では初めての仕事を頼むとき、AIの方から質問してもらっています。

![AIの方から質問してもらう。誰の何をする係か、いつもの手順は、どこまでで合格か](/blog/claude-code-neteruma-ai-shain/diagram-5-questions.webp)

たとえば、次のような質問です。

1. 誰の、何を、どうする係ですか
2. いつもの手順を教えてください
3. どこまでできたら合格ですか

頼み方は、次の1文で足ります。

> この仕事を任せたいです。作り始める前に、分からないことを1問ずつ私に質問してください。答えは最後に「会社のメモ」にまとめてください。

新しく入った社員を迎えるのと同じです。最初は隣で教えて、教えた内容を紙に残します。

## 寝ている間に動く条件

「寝ている間に働く」で一番つまずきやすいのが、ここです。

今回の作り方（ローカルのスケジュール）で動くのは、パソコンの電源が入っていて、眠っておらず、Claude のアプリが開いている間だけです。設定の「Keep computer awake（コンピューターをスリープさせない）」をオンにしても、ノートパソコンはふたを閉じると眠ります。

眠っていた間の回は、とばされます。次に起きたとき、直近7日分のうち最新の1回だけをあとから実行します。6日眠っていても、6回分はまとめて動きません。そして、朝7時の仕事が夜に動くこともあります。時刻が大事な仕事なら「午後に始まったときは作らずに、そう書いて」のように足しておきます。

### パソコンを閉じても動かしたい場合

選び方は3つあります。

![どこで動かすか。今回の作り方はパソコンの起動が必要。Claude Codeのクラウドは閉じても動く試験提供。Coworkのスケジュールはクラウドなら閉じても動く](/blog/claude-code-neteruma-ai-shain/diagram-6-where.webp)

| 動かす場所 | 閉じても動くか | 向く仕事 |
|---|---|---|
| 今回の作り方 | 動かない | 手元のフォルダを使う仕事 |
| Claude Code のクラウド | 動く | 開発寄りの仕事。研究プレビュー（試験的な提供） |
| Cowork のスケジュール | 動く（手元のフォルダを選ばない場合） | メールや予定、Claude に保存したファイルを使う仕事 |

Cowork（コワーク）は、Claude のアプリの中で、事務の仕事をまとめて任せられる機能です。有料プランで使えます。クラウドで動かすときは手元のフォルダを読めないので、必要なつなぎ口やファイルを先に渡します。

閉じても動く2つは、止め方が今回の作り方と違います。

- Claude Code のクラウド：原則 Auto で始まり、つないであるコネクタが最初は全部入ります。パソコンに書いた自分用の許可のルールも届きません。使わないコネクタ、特に送信できる物は外します
- Cowork：承認のモードによっては、送信まで確認なしで進みます。メールを使うなら Manual にして、送信に「すべての回で許可（Allow for all scheduled runs）」は選びません

最初の1体は、今回の作り方がいちばん分かりやすいと思います。目の前のフォルダで、何が増えて何が変わったかを自分の目で見られるからです。

ほかのAIで試したい方は、[Geminiのタスクの記事](/blog/gemini-tasks-muryou/)で、無料でできる範囲をまとめています。

## 本物のメールにつなぐ前に、人が決める所

弊社では、送る・公開する・消すは人が決める、を基本にしています。やり方は細かく指定しません。その代わり、最後に人が承認する所を残します。メールの送信などは、お願いの文だけでなく設定でも止めています。

![最後に決めるのは人。送る、公開する、消す、お金の4つは人が確かめる](/blog/claude-code-neteruma-ai-shain/diagram-7-human.webp)

皆さんの会社では、ここにお金も足してください。支払い、金額の確定、契約は、人が確かめます。

### Gmail のつなぎ口は、送信までできます

ここは本当に大事です。Claude の Gmail のつなぎ口は、下書きだけでなく、送信・返信・転送もできます。公式のヘルプには、Auto のモードでは確認なしで実行される場合があり、自動の安全確認が危ない操作を見落とすこともある、と書かれています。

つなぐ前に、次の3つを決めてください。

1. 送信・公開・削除・支払いにつながる道具は、Claude Code の許可のルールで「禁止」か「毎回確認」にします。禁止のルールに当てはまる操作は、どの許可のモードでも止まります
2. 自動で動かす仕事を、Auto や Bypass permissions のまま置きません
3. 使わないつなぎ口は切り離します

見落としやすい点が1つあります。会社の管理者がつなぎ口に設定する「承認が必要（Needs approval）」は、今回の作り方には届きません。公式の説明では、アプリの Code のタブでパソコン内の仕事に届くのは「禁止（Blocked）」の方です。個人で選ぶ「常に確認（Always ask）」が届くという説明も見当たりません。なので当てにせず、使わないつなぎ口は切り離すのが確実です。

許可のルールは、日本語のお願い文ではありません。設定のファイルに、道具ごとに書きます。送る道も、つなぎ口、コマンド、ブラウザーの操作と1つとは限りません。なので、ここは詳しい人と一緒に進めてください。

頼む文や CLAUDE.md の「送信はしない」は必要ですが、それはお願いです。設定で止める所までやって、初めて仕組みになります。

## よくある質問

### プログラミングができなくても作れますか

今回の範囲なら、日本語で頼むだけです。社内のシステムにつなぐ所や、許可のルールで細かく止める所は、詳しい人と一緒に進めるのがおすすめです。

### 無料プランでもできますか

Claude Code には有料プランが要ります。料金は変わることがあるので、[Claude の料金のページ](https://claude.com/pricing)で確かめてください。自動で動いた分も、普段の利用枠から引かれます。上限に当たると止まりますが、追加の利用枠（Usage credits）をオンにしていると、別料金で動き続けることがあります。

### Windows でもできますか

できます。Claude のパソコン用アプリは Mac と Windows にあります。画面の名前や並びは、アプリの版によって少し違います。

### 「ルーティン」と「スケジュール」は違う物ですか

ルーティンは、Claude Code のクラウドのスケジュールタスクの以前の名前です。アプリによっては、今も「ルーティン」と表示されます。大事なのは名前より、このパソコンで動くのか、クラウドで動くのかです。

### 会社の情報を入れても大丈夫ですか

先に契約と設定を見てください。個人向けのプラン（Pro・Max など）は、入力した内容をAIの学習に使うかどうかを設定で選べます。Team と Enterprise は、既定では学習に使われません。お客様の情報を入れてよいかは、会社の決まりと相手との約束も確かめます。

### スマホだけで作れますか

今回の作り方には、パソコンが要ります。手元のフォルダを、起きているパソコンの上で読むからです。

### 一度に何体も作った方がいいですか

1体からをおすすめします。翌朝に中を見て直す、を数日続けると、自社の決まりが会社のメモにたまります。そのメモは、2体目にも渡せます。

## 始め方3ステップ

1. 今日：3つの目安で、任せる仕事を1つ選びます
2. 明日：練習用のフォルダで、5行を頼んで「今すぐ実行」まで進めます
3. 今週中：3日続けて朝に中を開き、問題がなければ、止める設定をしてから自社の仕事に置き換えます

AIエージェントは、やってくれるAI。仕事ごとに道具とノウハウを渡す。送る・公開する・消すは人が決める。この3つを押さえて、まずは1体、作ってみていただければと思います。
