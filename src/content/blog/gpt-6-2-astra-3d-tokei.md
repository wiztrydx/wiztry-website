「新商品の紹介動画を作りたい。でも、試作品の撮影や3DCGの制作会社への依頼は、うちの規模では重い」。そう感じている中小企業の方に向けて、AIに3Dの商品動画を作らせた結果を、作品と作り方に絞ってまとめます。

使ったのは、OpenAI が11月17日に出した ChatGPT の新しいモデル GPT-6.2 Astra です。架空の高級腕時計を1本、部品から3Dで作り、ばらばらの部品が組み上がるまでの30秒の映像にさせました。指示文は1回だけです。

結論から言うと、1回の指示で、製品の商品動画の入り口まではできます。ただ、金属の質感はまだ公式の作例のほうが上で、そこに近づけるには、もうひと手間が要りそうです。

## 完成した作品

できたのは、架空のブランド「ORIELUNE」の手巻きの機械式腕時計「PLICA 01」の、30秒の商品動画です。

真っ暗な空間に、ばらばらの部品が浮かんでいるところから始まります。中の歯車やぜんまいが組み上がり、文字盤と針、ケースとガラス、りゅうず（時刻を合わせるつまみ）、ベルトの順に1本の時計になります。最後は、裏側で歯車が回り、表で秒針が進むところを見せて、製品名のカットで締めています。

撮影は一切していません。時計の形も、金属やガラスの質感も、光もカメラの動きも、すべて3Dのソフトの中で作ったものです。ブランドも製品もAIが考えた架空のもので、実在の時計のブランド名やロゴ、そっくりな形は使わないように指示しています。

部品は174個です。数は Claude（Anthropic のAI）に3Dのファイルを数えさせて、Astra の報告と一致することを確かめました。

| 部品のまとまり | 数 |
|---|---|
| 歯車・ぜんまいの箱など、時計を動かす機械 | 31 |
| 機械を押さえる板、てんぷ（時を刻む振り子の輪）、ねじ、石など | 61 |
| 文字盤と目盛り | 31 |
| 針 | 8 |
| ケース・ガラス・りゅうず | 23 |
| ベルトまわり | 20 |
| 合計 | 174 |

YouTube の動画では、この映像に、英語のナレーションと、秒針の音、部品がはまる音をあとから足しています。絵は、Astra が作ったままです。

## 作り方

### 使った道具

| 役割 | 使ったもの |
|---|---|
| 時計の設計、3Dの制作、書き出し、確認 | GPT-6.2 Astra（Codex から使用） |
| 3Dのソフト | Blender |
| 英語のナレーション（あとから） | Gemini の音声合成 |
| 秒針と、部品がはまる音（あとから） | Final Cut Pro に付いている効果音 |

Codex は、パソコンの中でファイルを作ったり、ソフトを動かしたりしてくれる OpenAI の道具です。もとはプログラム開発向けですが、頼むのは日本語の文章で大丈夫です。今回は文字を打ち込んで使う版で Astra を選び、考える深さの設定は Extra High（とても深く考える設定）にしました。Codex そのものについては「[OpenAI Codexとは？](/blog/openai-codex-kaisetsu/)」で詳しく説明しています。

Blender は、プロも使う本格的な3Dのソフトで、無料で使えます。ただ普通は、使い方を覚えるだけで何か月もかかります。今回は、Astra が自分でプログラムを書いて Blender を動かし、部品を1つずつ作っています。私は Blender を操作していません。

### 手順は4つ

1. Blender を入れたパソコンで Codex を開き、作業用のフォルダを決めて、モデルに GPT-6.2 Astra を選びます。
2. 指示文を1回だけ渡します。途中で質問はできないので、迷ったら自分で決めて進めるように書いておきます。
3. 待ちます。Astra は、時計の設計、部品づくり、光とカメラ、動きの順に進め、小さな画質で試しに書き出しては直す、をくり返します。最後に本番の書き出しをして、できたコマを自分で確かめてから渡してきます。
4. 必要なら、音を足します。今回は、できあがりを見て、人の判断で英語のナレーションと効果音を足しました。

### 指示文のポイント

指示文に書いたのは、大きく次の4つです。

- 作るもの：架空の高級な機械式腕時計。部品が浮かんだ状態から組み上がり、時計が動いているところを見せて、製品名で締める30秒の映像。部品は100個以上を目安に
- 作り方の決まり：形・質感・光・動きは、全部 Blender の中でプログラムで作る。外から3Dのモデルや写真を持ってこない。お金がかかる生成サービスは使わない
- 守ること：実在の時計のブランド名やロゴを入れない。実在の有名な時計にそっくりな形にもしない
- 渡す前に：書き出したコマを自分で見て、部品のめり込み、取り残された部品、読めない文字、暗すぎる・白く飛んだカットがないか確かめて、直してから渡す

### かかった時間

| | |
|---|---|
| 指示を渡してから完成まで | 約1時間半 |
| そのうち本番の書き出し | 約66分 |
| 部品の数 | 174個 |
| できた映像 | 横1920×1080・30秒 |

1時間半のうち、半分以上は書き出しの時間です。書き出しは私の Mac の上で動いていたので、ここはパソコンの性能によって変わります。使ったのは、ChatGPT の有料プランで使える Codex と、無料の Blender です。動画生成のサービスは使っていないので、生成のクレジットも使っていません。

### Astra が自分でやっていたこと

Astra の報告を読むと、細かいところまで自分で考えて作っていました。

- 歯車は歯の1枚1枚まで作り、かみ合う歯車どうしが、歯の数に合った向きと速さで回るようにしている
- 文字盤の放射状の筋96本は、模様の絵ではなく、本当の凹凸として作っている
- 光は面の照明7つと、光を返す板5枚。カメラは8台を切り替えている
- 試しの書き出しで見つけた、反射で針が見えにくいところとベルトの付け根のすき間、本番の書き出しで見つけた、ねじが小さな文字に重なるところを、自分で直してから渡している

## ここから分かること：中小企業でも、3Dの商品動画の入り口が作れるようになった

### 1. 3Dのソフトを覚えなくても、言葉で頼めるようになった

これまで3Dの商品動画は、3Dのソフトを使いこなせる人か、制作会社にお願いするものでした。今回は、何か月もかかる Blender の操作を、まるごと Astra が引き受けています。人がやったのは、何を作るかと、守ってほしいことを文章にすることでした。

逆を返せば、作りたい製品のイメージと、守ってほしい決まりさえ言葉にできれば、3Dの商品動画のたたき台が作れるということです。

### 2. 向いている仕事

- 商品の3D動画や、商品を回して見られるページを、外に頼まずに作ってみたい
- 製品や建物を、お客様に立体で見せたい。特に、不動産会社さんやハウスメーカーさんには使えると思います
- これから Blender を使った動画づくりに挑戦してみたい人の、最初の一歩

ちなみに、同じように1回の指示で、架空のマイクをマウスや指で回したり、部品をばらして中を見せたりできる発表ページも作れました。部品をばらして中の仕組みを見せる見せ方は、機械や製品の説明にも使えそうです。

### 3. まだ苦手なこと

1つ目は、質感の作り込みです。公式の作例の時計と比べると、金属の質感は公式のほうが上でした。公式の作例でも、よく見ると作り物だと分かるところがあり、実写の代わりにはまだなりません。

2つ目は、音です。Astra は音もプログラムで作ってくれましたが、報告には「スピーカーで聞いて確かめてはいない」と書いてありました。今回は Astra の音を外して、ナレーションと効果音を人の耳で選び直しています。音は、最後に人が確かめる必要があります。

3つ目は、細かいところの見え方です。Astra 自身も、ガラスが閉じる斜めのカットで、細い目盛りが一時的に薄く見えると報告していました。設定を上げて、やり取りを何回か重ねれば、もう少し公式の作例に近づけられると思っています。

なお、Blender を使った3Dは、Claude の Fable や Opus も同じくらい得意です。Astra だけの特別な力ではないので、ふだん使っているAIで試してみるのもいいかなと思います。

### 4. どこから始めるか

まずは、自社の製品を1つ選んで、「部品が組み上がる30秒の動画」を1回頼んでみてください。指示文には、実在のブランドに似せないこと、渡す前に自分で確かめて直すこと、の2つを必ず入れておくのがおすすめです。1回目で入り口まで作れたら、気になるところを言葉で伝えて、少しずつ仕上げていけば十分かなと思います。
