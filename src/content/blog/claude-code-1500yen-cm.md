「動画生成AIを試してみたい。でも、サブスクをいくつも契約するのは気が引けるし、画面に打ち込んでは待つ作業も続かなそう」。そう感じている中小企業の方に向けて、私が Claude Code（Claudeのデスクトップアプリで使える、パソコンの中で作業してくれるAI）に予算1,500円を渡して、CMを作らせた手順を全部書きます。

結論から言うと、シナリオ、画像、動画、ナレーション、演出までを Claude Code に進めてもらえました。ただし、案を選ぶことと、カット割りを直すことは人の仕事でした。約1,500円はAPIの利用料を公式の単価から計算した額で、Claude の有料プラン、編集ソフト、曲の費用は別です。

YouTube で公開した動画の内容を、料金と順位を11月6日に公式ページで確かめ直して書き直しました。動画の画面に出したプロンプト（AIへの依頼文）を全文載せています。

## この記事の要点

- Claude に渡したのは、予算とゴールと、使っていい道具（APIキー3つ）です
- APIの費用は約1,500円でした（10月31日の単価・1ドル157.5円で計算）。Claude の有料プラン、編集ソフト、曲の費用は別です
- 動画生成AIの FLUX 3 Max は11月7日までの75%オフの値段です。11月8日以降は動画の費用が約4倍になり、同じ作り方なら全体で約3,700円です
- AIに全部任せた編集は物足りず、カット割りは人の手で直しました。AIは作る、人は選んで直す、という分担です

## 先に：11月8日から動画の費用は約4倍になります

作る前に、ここだけ押さえてください。FLUX 3 Max の値段は、fal（いろいろな動画生成AIを1つのキーで使えるサービス）の公式ページの表示で、720pが1秒0.0425ドルです。これは10月15日から11月7日までの75%オフの値段で、そのあとは1秒0.17ドルになります。

![11月8日から動画の費用は約4倍。5秒1本は約33円から約134円へ、全体は約1,500円から約3,700円へ。作る前にその日の値段で比べ直す](/blog/claude-code-1500yen-cm/diagram-1-price-change.webp)

同じ本数を作り直すと、全体は約1,500円から約3,700円になります。11月7日の当日が割引に入るのか、何時までなのかは公式に書かれていません。なので、作る日の値段を必ず確かめてください。この記事のプロンプト7が、そのための頼み方です。

## 動画の補足：正確にはこうです

動画で話した言葉と、制作の記録や公式の情報が違う所があります。この記事では記録と公式の情報のほうで書くので、先に直しておきます。

1. 「合計1,500円ぴったり」：公式の単価から計算した額（1,499.7円）で、管理画面の実額を確かめた記録ではありません。Claude の有料プラン、編集ソフト、曲の費用も入っていません
2. 「Gemini でBGM」：Gemini で作ったのはナレーションです。完成版の曲は、私が別に用意した曲です。「曲と効果音 約341円」は試作の費用です。試作の曲は完成版に入っていません。効果音も、動画で話したとおり結局あまり使いませんでした。試作の曲は ElevenLabs、Lyria 3.5、MiniMax Music 3 で作り、fal のキーで動かしました
3. 「XML」：初めての人が同じことをするときの手順として紹介しました。記録に残っている XML はAIのカット割りの案から作ったもので、形式の検査には合格していますが、Final Cut Pro に読み込んで確かめた記録は残っていません
4. 「手を動かしたのは約15分」：測った記録はありません。私の体感の話として読んでください
5. 「制作費100万円以上」：Claude に渡した目標の言葉です。できたCMが100万円のCMと同じ価値だ、という意味ではありません。動画の「After Effects の依頼は1カット数万円から数十万円」も、出典を確かめられていないので、この記事には書きません
6. 「性能ランキング12位」：Artificial Analysis（AIの性能を比べる第三者のサイト）の順位です。11月6日は12〜13位タイでした。順位は変わります。また、動画では「最高性能なら Seedance や Kling」と話しましたが、同じ順位表の上位15位に Kling はありません
7. 「1枚3円以下」：私が出した目標です。実際に3円以下だったのは40枚のうち3枚で、平均は約5円でした
8. 「今一番おすすめの GPT Image 2.5」：撮影の時点の話です。11月4日に OpenAI から Images 2.6 が発表されました。このCMは GPT Image 2.5 で作っています
9. 「白黒がメインだった1960年代に鮮やかな色で驚かせた」：AIから聞いた話で、出典を確かめていません。案を選んだ理由としてはそのとおりですが、歴史の事実としては書きません
10. 「30秒のCM」：Claude に頼んだ長さは30秒です。私が編集した完成版は、エンドカードまで入れて37.5秒です

調査の約14円は Grok を1回使った分で、3つのキーとは別です。

逆を返せば、比較、試作、調査、AIの確認を外すと、同じ流れは約950円でできます。ただし曲は別に用意する前提で、これも11月7日までの値段です。11月8日以降は約3,150円です。

もう1つ、正直なところを書きます。約1,500円は「使った分」で、最初に払うお金はもっと多くなります。

APIは前払いが基本で、OpenAI は最低5ドル（約790円）からです。Gemini も有料の設定なら最低5ドルから、fal はクレジットを先に買います。余った分は次の動画に使えますが、1年ほどで失効し、原則返金されません。

これとは別に、Claude Code を使うには Claude の有料プランが要ります。公式の料金ページの表示で、Pro は月払い20ドルです（税の扱いは地域で変わります）。無料プランでは使えません。

## 全体の流れと、人の出番

流れは6段階です。お昼に始めて、夕方には完成しました。

![CMができるまでの流れ。準備、シナリオ、画像、動画、編集、仕上げの6段階。作るのはAI、選んで直すのは人](/blog/claude-code-1500yen-cm/diagram-3-flow.webp)

Claude には、実写のような映像を生成する力がありません。普段は計画やアイデア出しを手伝うAIです。でも、画像や動画のAIを使うための鍵を渡すと、撮影までできるようになります。たとえるなら、企画が得意な部下に、外のスタジオの鍵を渡すイメージです。

Claude にAPIキーで動画を作らせる良さは3つあります。

1. 動画生成AIのサブスクに入らなくても、使った分だけで済みます
2. APIのキャンペーン中は、サブスクより安く作れる場合があります
3. 手間が一気に減ります。プロンプトを打って、ボタンを押して、再生して確かめて、気に入ったものをダウンロードする、という作業をAIが代わりにやってくれます

自分は、上がってきたものを見る監督になれます。一方で、たくさん使うとサブスクより高くなります。なので、費用を見ながら使ってください。

## 準備編：APIキーを3つ用意する

API（エーピーアイ）は、AIのサービスをほかのソフトから使うための窓口です。APIキーは、その窓口を通るためのパスワードのようなものです。今回は3つ用意しました。

![APIキーで道具が使える。Claude CodeがOpenAIで画像、falで動画、Geminiで音を作る](/blog/claude-code-1500yen-cm/diagram-4-api-keys.webp)

- OpenAI：画像（GPT Image 2.5）
- fal：動画（FLUX 3 Max など）
- Gemini：ナレーション

fal は、初めて聞く方も多いと思います。いろいろな動画生成AIを1つのAPIキーで選んで使える、自動販売機のようなサービスです。

![falは動画生成AIを選べる自動販売機。1つのAPIキーでKling、Seedance、FLUX、MiniMaxを選べる](/blog/claude-code-1500yen-cm/diagram-5-fal.webp)

### キーを作る前に、お金の設定を確認する

一番つまずきやすいのがここです。3社それぞれ、お金の仕組みが違います。

![キーを作る前にお金の設定を確認。falは前払いで365日で失効、OpenAIは最低5ドルで自動チャージは切る、Geminiは有料の設定は最低5ドルから、キーはチャットに貼らない](/blog/claude-code-1500yen-cm/diagram-6-prepay.webp)

1. fal：クレジットを前払いで買います。カード払いで、登録だけでAPIに使える無料クレジットは、私が調べた範囲では見つかりませんでした。買った分は365日で失効し、原則返金されません
2. OpenAI：最初の購入は最低5ドル、初期値は10ドルです。購入の画面で「Use auto-reload」（自動チャージ）が初期設定でオンになっています。意図しないなら、ここで切ってください。買った分は1年で失効し、原則返金されません
3. Gemini：ナレーションのモデルには無料枠があります。ただし無料枠だと、入れた内容が Google の製品改善に使われます。会社の素材を扱うなら有料の設定にしてください。新規は前払いで最低5ドル、未使用分は12か月で失効します

OpenAI の案内には、残高が尽きてもAPIがすぐ止まるとは限らない、とも書かれています。なので、残高を上限の代わりにせず、このあとのプロンプト3の「くわしく頼むなら」にある、予算を超える前に止まる仕組みを Claude に作ってもらいます。

OpenAI は、組織の確認（本人確認）を求められることがあります。動画の準備をする日に慌てないように、先にキーまで作っておくのがおすすめです。

### プロンプト0：APIキーを使えるようにする

手順は3つです。

1. それぞれの管理画面でキーを作ります。[fal](https://fal.ai/dashboard/keys)、[OpenAI](https://platform.openai.com/api-keys)、[Gemini](https://aistudio.google.com/apikey) です。fal のキーは作った時に1回しか表示されません
2. 下のプロンプトを Claude Code に貼ります
3. 教えてもらったファイルを自分で開いて、キーを貼って保存します

> fal と OpenAI と Gemini の APIキーを、環境変数として使えるようにしたいです。
>
> キーはこのチャットには貼りません。私が自分でキーを貼るためのファイルを、自分のアカウントだけが読める権限で作って、場所を教えてください。
>
> そのあと、キーの中身を表示せずに、それぞれのキーで呼び出しができるか確かめる方法を教えてください（お金がかからない確かめ方で）。

APIキーは、チャットに貼らないでください。会話に残ります。画面を録画するときも映さないように気をつけてください。

### あと2つ準備するもの

仕上げで使う HyperFrames（動画に重ねる演出を作れる無料の道具）と FFmpeg（動画を切ってつなぐ道具）は、[前回の記事の「準備1」](/blog/claude-code-motion-graphics-cm/)のプロンプトで入ります。カット割りを自分で直すなら、編集ソフトも使います。動画では Final Cut Pro です。

準備ができたら、Claude Code に予算とゴールを伝えます。

### プロンプト1：予算とゴールを伝える

Claude のデスクトップアプリの「Code」タブで、作業用のフォルダを1つ決めてから、上から順に貼って使います。ここからのプロンプトは、動画の画面に出した文そのままです。ランボルギーニ、30秒、1,500円、FLUX 3 Max などは、自分の題材に書きかえて使えます。

> 予算1,500円で、ランボルギーニの30秒の架空CMを作りたいです。
>
> 制作費100万円以上に見えるクオリティを目指してください。

### プロンプト2：3つの条件を伝える

> 予算：API利用料で1,500円以内
>
> ゴール：30秒の架空CM
>
> 使ってよい道具：画像・動画・音声のAPI

## シナリオ編：AIが6案、選ぶのは人

### プロンプト3：シナリオの条件

> ランボルギーニの魅力をアピールする、30秒の架空のCMを作ってください。
>
> 制作費100万円以上のCMを目指してください。
>
> 予算はAPIの利用料で1,500円以内。
>
> NG事項として、途中で車の形が変わる、物理的におかしい走り方、日本語の文字化け、
>
> そういう要素は一切なくしてください。
>
> まずは構成案とイメージ画像を出してください。

「途中で車の形が変わる」「物理的におかしい走り方」「日本語の文字化け」の3つをNGにしました。AIが描く映像の文字は崩れやすくて、一番チープに見えるからです。

くわしく頼むなら、上の文のあとに次を足します。予算を超える前に止まる仕組みと、人が決める所で止まる約束が入っていて、途中で迷子になりません。

> APIを呼ぶたびに費用を台帳に記録して、次の呼び出しで予算を超えるなら、呼ばずに止まる仕組みを最初に作ってください。
>
> 品質：
>
> ・【車】の形が途中で変わらないこと
>
> ・物理的におかしい走り方をしないこと
>
> ・AIが描く映像の中に文字を入れないこと（日本語の文字化けが一番チープに見えるため）
>
> ・シチュエーションはありえなくてOKです。映像と【車】のリアルさだけ最優先にしてください
>
> 進め方：作業はあなたに任せます。私は決めるところだけ手伝います。私に決めてほしいところでは、選択肢を見せて止まってください。
>
> 構成案は【6】案。案ごとにイメージ画像を1枚ずつ作って、1枚に並べて見せてください。私が1つ選ぶまで、動画は作らないでください。

このプロンプトで、シナリオとイメージ画像が6案出てきました。牛の大群を率いて走る案や、空席のオペラ座で排気音のコンサートをする案もあって、どれも捨てがたかったです。

![AIが出したシナリオ6案のイメージ画像。白黒の街、牛の大群、霧の農場、オペラ座、時間が止まった朝、雲の上の一本道](/blog/claude-code-1500yen-cm/diagram-7-six-ideas.webp)

どれにするかは人が決めます。私は左上の、白黒の街に色が1つだけある案を選びました。ただかっこいいだけではなく、ストーリー性があると思ったからです。

### プロンプト4：採用する案を伝える

> 白黒の街に、オレンジの車だけが色を持つ案を採用します。
>
> ストーリー性を生かして、この案で制作を進めてください。

## 画像生成編：先にお手本を3枚作る

シナリオが決まったら、動画の元になる画像を先に作らせます。ここまでは1回1回の失敗が安いので、動画に進む前に絵を固めるのがコツです。使ったのは GPT Image 2.5 です。

細かなコツが1つあります。主役の車の見た目を固定するために、まず前、後ろ、真横の3枚を作らせて、ほかの画像のお手本にさせました。

![お手本として作った車の3枚。斜め前、斜め後ろ、真横](/blog/claude-code-1500yen-cm/diagram-8-master.webp)

### プロンプト5：画像の条件とお手本

> 選んだシナリオの画像を、GPT Image 2.5で作ります。
>
> まず車の前・後ろ・真横のお手本を3枚作ってください。
>
> 全カットで同じ車に見えるようにしてください。
>
> 画像の予算は、1枚3円以下を目標にしてください。

くわしく頼むなら、次を足します。

> 【車】の形・色・細部を細かく書いた固定の文を作り、全カットの画像の先頭に入れてください。ロゴ・バッジ・ナンバー・文字は入れないでください。
>
> 1枚3円以下は、品質の設定で調整してください（お手本の画像を参照に渡す分は少し上がって構いません）。
>
> お手本ができたら、全カットの設計図を作ってください（カットごとの撮り方・動き・音）。カットごとの画像を、お手本を参照に作って一覧で見せてください。私が確認するまで、動画は作らないでください。

そのあと、各シーンの画像を一気に作らせて、AI自身にも形が崩れていないかをチェックさせました。

### プロンプト6：AIにも画像をチェックしてもらう

> この画像を確認してください。
>
> 車の形は、お手本と一致していますか？
>
> 白黒の世界で、車以外に色が付いていませんか？
>
> 問題のある画像だけ、修正案を出してください。

AIのチェックにも見落としがあるので、最後は人の目で見ます。全部の画像が一覧で出てくるので、車の形が変わっていないか、違和感がないかを確かめて、問題のある画像だけ作り直させます。

たとえば下の画像は、完全に白黒で作ってほしかったのに、オレンジの三輪の小型トラックが混ざっていました。こういう画像を指定して作り直させます。

![白黒の広場にオレンジの三輪の小型トラックが混ざった画像。作り直しの例](/blog/claude-code-1500yen-cm/diagram-9-tricycle.webp)

全部で40枚、約207円でした。1枚の待ち時間は、記録の真ん中の値で約20秒です。

## 動画生成編：AIは値段で選びました

候補は Kling、Seedance、FLUX、MiniMax です。Claude と相談して、FLUX 3 Max に決めました。性能で1位のモデルではありません。理由は値段です。

30秒のCMには、5秒の動画が最低6本要ります。撮り直しも考えると、30本くらいは作れないと厳しいと思いました。予算を全部動画に使っても、Seedance なら4本で20秒にしかなりません。FLUX 3 Max なら44本作れます。

![同じ予算1,500円でも、Seedance 2.5は4本、FLUX 3 Maxは44本作れる。撮り直しの余裕が仕上がりを変える](/blog/claude-code-1500yen-cm/diagram-10-budget-retries.webp)

11月6日に fal の各モデルのページと Artificial Analysis で確かめ直した表です。本数は、1,500円を全部動画に使った場合です。

| モデル | 5秒1本 | 本数 | 順位 |
|---|---|---|---|
| Seedance 2.5 | 約372円 | 4本 | 1位 |
| MiniMax H3 | 約47円 | 31本 | 4位 |
| HeyGen Video 1 | 約16円 | 95本 | 5位 |
| H3 Max | 約44円 | 34本 | 8位 |
| FLUX 3 Max（11/7まで） | 約33円 | 44本 | 12〜13位 |
| FLUX 3 Max（11/8から） | 約134円 | 11本 | 同じ |
| Kling 4.0 | 約124円 | 12本 | 15位までに無し |

768pや720pは画面の細かさの表示で、数字が大きいほど細かくなります。MiniMax と HeyGen は768p、ほかは720pです。H3 Max の値段は11月15日までで、16日からは5秒約63円です。順位は Artificial Analysis の「画像から動画」で、別の順位表の Arena では FLUX 3 Max はまだ載っていません（11月5日の表示）。

表を見ると分かるとおり、FLUX 3 Max が一番安いわけでも、一番性能が高いわけでもありません。私が選んだのは、この予算で本数が作れることと、11月7日まで75%オフだったこと、それからまだ使ったことがないモデルだったからです。Kling と Seedance は値段で外したので、実物で比べたのは MiniMax の H3 Max と H3 Max Turbo だけです。HeyGen Video 1 は試していません。

実際に別の Claude に比べさせたら、第一候補は FLUX 3 Max ではありませんでした。なので「FLUX が一番」ではなく、作るその日の値段で比べてもらってください。動画生成AIはセールをよくやっています。

### プロンプト7：今の料金で動画生成AIを比べる

> 動画生成AIの料金と性能を比較してください。
>
> 5秒の動画1本の金額をそろえて比べてください。
>
> 予算1,500円の中で、作り直す余裕も残したいです。
>
> 今の料金で候補を調べてください。

くわしく頼むなら、次を足します。順位と値段だけでは決めきれないので、同じ画像で試し撮りしてから決めます。

> 料金は公式ページで、品質は Arena などの外部の順位で確かめて、この予算で何本作れるかまで表にしてください。
>
> 候補を2、3個選んで、同じ画像で5秒ずつ試し撮りして、見比べられるようにしてください。私が決めるまで、本番の生成はしないでください。

## 全カット生成：試し撮りを入れて22本

シナリオと画像がそろった時点で、もう絵コンテがある状態です。なのでプロンプトはシンプルです。

### プロンプト8：絵コンテ通りに動画を作る

> この絵コンテ通りに、FLUX 3 Maxで動画を作ってください。
>
> 車の形と色をそろえてください。
>
> 背景の石畳や建物の形も保ってください。

くわしく頼むなら、次を足します。

> 【FLUX 3 Max】、720p、1本5秒、音も一緒に。ただし曲と声は入れないでください（映像の中の音だけ）。
>
> 【車】の形を崩さないために、本物のカメラでできる置き方だけにしてください（三脚で固定・並走・追走・【車】に固定・ドローン）。カメラが【車】の周りを回り込むのは、なしです。
>
> カメラが止まっているカットは、カメラの位置を同じにして【車】の位置だけ進めた画像を、最初のコマと最後のコマに渡してください。同じ画像を2回渡すと、車輪や背景が止まって見えます。並走や追走は、最初のコマだけ渡してください。走っているカットの画像は、車輪に回転のぶれを入れてください。
>
> できたら自分でコマの一覧を見て検品し、【車】の形が崩れたカットと、車輪や背景が止まっているカットだけ作り直してください。

試し撮りも入れて22本作ってくれて、約736円でした。1本の待ち時間は、記録の真ん中の値で約47秒です。完成版に入ったのは、このうち14本です。

![FLUX 3 Maxで作った動画素材の一覧（試し撮り2本を除く20本）。白黒の街とオレンジの車、色のついた街、ドローンの引き](/blog/claude-code-1500yen-cm/diagram-11-flux-sheet.webp)

予算が少し余ったので、同じ写真を MiniMax H3 Max でも動かしてみました。MiniMax のほうは、走っているうちに石畳が普通の道路に変わってしまいました。今回のケースでは、FLUX のほうが安定していました。

![同じ写真をFLUX 3 Max、H3 Max、H3 Max Turboで動かした比較。FLUXは石畳のまま、H3 Max系は普通の道路に変わった。札の値段は10月31日の単価](/blog/claude-code-1500yen-cm/diagram-12-compare.webp)

ここまでで動画の素材がそろいました。ここまで私は手を動かさず、声で指示しただけです。

## 編集編：ここが、AIでうまくいかなかった所

試しに、カット編集を全部 Claude に任せてみました。

### プロンプト9：カット編集の初稿

> そろった動画を使って、30秒のCMを編集してください。
>
> シナリオに合う順番にカットを並べてください。
>
> テンポのよい案を作って、確認できる動画にしてください。

結論から言うと、物足りなかったです。クオリティが全然足りませんでした。

原因は、Claude が動画を音の波形と静止画で理解していることです。人の感性で動画を見ることができません。カットを並べることはできても、BGMに合わせて盛り上げていくような、タイミングが大事な表現はまだ苦手です。

![AIは動画を静止画と音の波形に分解して理解する](/blog/claude-code-1500yen-cm/diagram-13-ai-view.webp)

なので、ここは人の手でやりました。完成版のカット割りは、私が Final Cut Pro で組み直しています。

![Final Cut Proの実際のタイムライン。人の手で組み直したカット割り](/blog/claude-code-1500yen-cm/diagram-14-timeline.webp)

### 人とAIで一緒に編集するなら：XML

人とAIの間をつなぐやり方に、XML があります。どの映像をどの順番で並べるかを書いたファイルです。動画そのものではなく、設計図だと思ってください。

### プロンプト10：Final Cut Pro へ受け渡す

> このカット割りを、Final Cut Proで読み込める
>
> XMLファイルとして書き出してください。
>
> 各映像の順番と使用区間を引き継げる形にしてください。

くわしく頼むなら、次を足します。

> 動画はコピーせず、元のファイルを参照してください。書き出したら、Final Cut Pro に入っている DTD で検証してください。

Final Cut Pro の「ファイル」→「読み込む」→「XML」で開くと、素材が並んだ状態から、カットのタイミングを手で直せるはずです。

![XMLで人とAIをつなぐ。AIのカット割りをXMLにして編集ソフトで開き、人がタイミングを調整する](/blog/claude-code-1500yen-cm/diagram-15-xml.webp)

ここは補足のとおり、書き出しと形式の検査までは確かめましたが、Final Cut Pro に読み込む所の記録は残っていません。試すときは、まず短いカット割りで開けるかを確かめてください。

カット割りで手を動かした時間は、私の体感で約15分でした。素材が手元にそろっていて、タイミングを合わせるだけなので、普段の編集に比べるとかなり楽でした。

## ナレーションと曲

ナレーションは Gemini で作りました。英語の原稿もAIが書いたもので、「The world was never meant to be gray. Give it color.」という内容です。読み上げの費用はほぼかかりません。

### プロンプト11：ナレーションと BGM

> この素材とシナリオにぴったり合うナレーションとBGMを作ってください。

くわしく頼むなら、次を足します。

> Gemini API を使ってください。ナレーションは【英語】で、伝えたいことは【この車が世界に色を与える、ということ】です。原稿もあなたが書いてください。
>
> 声は3案作って、私が選べるようにしてください。

この文は動画の画面と同じなので BGM と書いていますが、完成版の曲は私が別に用意した曲です。使ってよいと確かめた曲を用意するか、AIに作らせてください。AIに作らせる場合の料金と規約は、[前回の記事](/blog/claude-code-motion-graphics-cm/)に書きました。

## 仕上げ編：After Effects 級の演出を足す

ここまでで、CMの形になりました。でも冒頭の動画には、キランと光る所や、色が広がる所があります。こういう演出は通常、After Effects（アフターエフェクツ。プロ向けの編集ソフト）で作るものです。これも Claude にやらせました。

### プロンプト12：エフェクトで仕上げる

> HyperFrames を使って、この動画に After Effects じゃないとできないようなハイクオリティな演出をかけてください。
>
> 画質は一切落とさないでください。

くわしく頼むなら、次を足します。元の映像を通さず、演出だけを透明な重ね物として作らせるのが、画質を落とさないコツです。

> ・タイミングと曲は変えないでください
>
> ・画質を落とさないために、元の映像は HyperFrames に通さず、演出だけを透明なレイヤーとして書き出して、元の映像に1回だけ重ねてください
>
> ・触らないカットは、元の映像と同じままか数値で確かめてください
>
> ・ナレーションの日本語の字幕も入れてください
>
> 0.25秒ごとのコマの一覧を作って、自分の目で検品して、合格したら見せてください。

HyperFrames は、Claude が動画に重ねる演出を作れる無料の道具です。左が演出の前、右が色の広がる途中です。

![演出の前と後。左は元の映像、右は街に色が広がっていく途中のコマ](/blog/claude-code-1500yen-cm/diagram-16-color-wave.webp)

AIは、頼んでいない所に演出を足すことがあります。全部のカットを通して、自分の目でも確かめてください。

最後に、自分の目で見て、自分の耳で聞いて、排気音と曲のバランスを Claude に直してもらいました。

### プロンプト13：音のバランスを直す

この文は動画の画面には出していません。【　】を書きかえて使います。

> 音の大きさがばらついていないか、聞いた時に違和感がないかをチェックしてください。
>
> 【排気音】が小さいので、書き出し直さずに音だけ直してください。
>
> 元の曲のファイルは【曲のファイル】です。今の動画の音と照らし合わせて、曲と映像の音に分けて、映像の音を少し上げた版と、曲を少し下げた版を見せてください。映像はそのままで、音だけ差し替えてください。

動画の時は、映像の音を +5dB、曲を −3dB にしました。

## よくある質問

### 本当に1,500円だけで作れますか

いいえ。APIの利用料が約1,500円で、Claude の有料プラン、編集ソフト、曲の費用は別です。11月8日以降は FLUX 3 Max の値段が上がります。最初は前払いの最低額もかかります。

### Claude の Pro で足りますか

ここは正直、測っていません。別の Claude に通しで試した時の使用量は約89万トークン（トークンはAIが読み書きした量の単位）で、Pro の枠に収まるかは確かめていません。足りない時は、間を空けるか、上のプランを検討してください。

### Final Cut Pro がないとできませんか

なくても進められます。別の Claude で試した時は編集ソフトを使わず、AIのカット割りをそのまま仕上げに回しました。ただ、人の手で直した時の差は大きかったです。ほかの編集ソフトで XML が開けるかは、私は試していません。

### 実在のブランドで作っていいですか

おすすめしません。fal の利用ポリシーは商標の侵害を禁止しています。今回のCMは非公式のファンフィルムで、許可を得たものではありません。

お仕事で使うなら、自社やお客様の商品で作ってください。ここは私の読み方で、法律の判断ではありません。

### 同じ映像が作れますか

作れません。生成は毎回結果が変わります。同じ流れで、同じくらいのものを目指す手順です。
