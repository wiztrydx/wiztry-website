AI に仕事をいくつも頼むと、今度は「どれが終わって、どれが自分の返事待ちなのか」が分からなくなります。AI を使って楽になるはずが、AI の見回りで忙しくなるわけです。

結論から言うと、新しい Claude のデスクトップアプリなら、この見回りを1つの窓口にまとめられます。2026年10月15日に、アプリの中の「Code」（Claude Code の画面）が丸ごと作り直されました。海外では「Claude 2.0」とも呼ばれています。

ただし「Claude 2.0」は、公式の製品名ではなく通称です。2023年に出た AI モデルの「Claude 2」とは別物です。古いモデルに戻す話でも、新しいモデルの話でもありません。パソコンに入れる Claude アプリの、画面と使い方の話です。

この記事は、11月7日に公開した YouTube 動画の内容を、記録と11月22日時点の公式の情報に照らして書き直したものです。プログラミングをしたことがない社長でも最初の1回を始められるように、入れ方から順に説明します。

## まず全体像：Claude 2.0で押さえるのは4つ

細かい操作の前に、全体を先に出します。覚えるのはこの4つです。

1. マスターセッション：窓口は1つのまま、仕事は何本も同時に
2. 新しい画面：今どこまで進んでいるかが、1つの画面で分かる
3. Remote Control：外出先のスマホから、返事と承認
4. API クレジット：対象のプランに毎月届く、API 専用の商品券

![Claude 2.0で押さえる4つ。マスターセッション、新しい画面、Remote Control、APIクレジット](/blog/claude-2-0-kanzen-koryaku/diagram-1-overview.webp)

言葉も先に3つだけ揃えます。会社に例えると、こうなります。

| 言葉 | 意味 | 会社に例えると |
|---|---|---|
| Claude Code | フォルダの中のファイルを読み、作り、直す AI | 手を動かす社員 |
| セッション | Claude との会話1つ分 | 社員1人に任せた仕事 |
| マスターセッション | ほかのセッションに振って、報告を受けるセッション | 部長 |

Claude Code と聞くと、プログラマーの道具に見えます。でも実際は、メールの下書き、営業資料、事務の書類づくりにも使えます。私も普段、同時に10本以上のセッションを動かしていますが、10本を1つずつ開いて回ることはしていません。

先に2つだけ、条件をお伝えします。

1点目。この記事の画面は、動画のために用意した撮影用の環境で、11月上旬に録画したものです。会社や仕事の中身は架空で、一部を伏せています。

2点目。画面の言葉や配置は、アプリの更新や表示する言語で変わることがあります。見当たらないときは、最後に載せた公式のページで確かめてください。

## 始め方：最初の1回は、この5ステップ

いきなり何本も同時に動かす必要はありません。まずは1本、送るところまでやってみましょう。

![最初の5ステップ。アプリを入れる、Codeを開く、フォルダを選ぶ、確認の仕方を手動にする、頼んで送る](/blog/claude-2-0-kanzen-koryaku/diagram-2-start.webp)

### ① アプリを入れる

[Claude の公式ダウンロードページ](https://claude.com/download)から、パソコン用のアプリを入れます。使えるのは macOS 13 以降と Windows 10 以降です（Linux はベータ版）。

すでに入っている人は、先に更新してください。Mac は「Claude」のメニュー、Windows は「ヘルプ」のメニューに更新の確認があります。入力欄の上に作業場所の選択が出ていたら、それは前の画面です。

### ② Codeを開く

有料プランのアカウントでログインして、左上の「Code」に切り替えます。文字ではなく「</>」のしるしだけで出ていることもあります。Code を使えるのは Pro・Max・Ultra・Team・Enterprise で、無料プランでは使えません。

### ③ フォルダを選ぶ

入力欄の下で、動かす場所（このコンピューター）と、仕事に使うフォルダを選びます。Claude はここで選んだフォルダを仕事場にします。

なので最初は、練習用のフォルダを新しく作って、資料のコピーを2〜3個入れてください。会社の共有フォルダを丸ごと渡すのは、慣れてからで十分です。

### ④ 確認の仕方を「手動」にする

同じ並びに、確認の仕方とモデル（AI の種類）の選択があります。確認の仕方は、社員にどこまで任せるかの設定です。

| 選び方 | どう動くか | 向いている場面 |
|---|---|---|
| 手動（Manual） | 書き換えや実行の前に聞いてくる | 最初はこれ |
| 編集を承認（Accept edits） | フォルダの中の書き換え・移動・削除などは聞かずに進む | やり方が固まった仕事 |
| 自動（Auto） | 安全の確認をしながら、聞く回数を減らす | 慣れてから |

初期設定が自動になっている場合があるので、最初の1回は目で見てください。モデルは、最初はそのままで構いません。

### ⑤ 頼んで送る

あとは日本語で頼んで、Enter で送るだけです。最初は「このフォルダの資料を読んで、要点を1枚にまとめてください。元のファイルは変えないでください」くらいの小さな仕事がおすすめです。違う方向に進んだら、停止ボタンで止められます。

手動にしていると、途中で「許可しますか」と聞かれます。ここで1つ注意です。目立つボタンが「常に許可」になっていることがあります。

![確認の札。右はしの矢印から一度だけ許可を選べる。常に許可を押すと削除などの確認も出なくなる](/blog/claude-2-0-kanzen-koryaku/permission.webp)

画面の説明にあるとおり、ファイルの書き込みでこれを押すと、そのセッションは「編集を承認」に切り替わります。書き換えだけでなく、フォルダの中の削除（rm という命令）なども聞かずに進みます。命令の種類によっては、許可が次回以降も残ります。

迷ったら右はしの矢印から「一度だけ許可」を選んでください。新入社員に最初から会社の印鑑を預けないのと同じです。

## 1つ目：マスターセッションで、窓口を1つにする

今回、私が一番使っている機能です。セッションの1つ1つが社員だとすると、マスターセッションは部長です。社員に仕事を割り振り、終わったら報告を受け取り、社長の自分にまとめて報告してくれます。

ただ、マスターセッションは公式の名前ではありません。専用のボタンもありません。海外の X や YouTube で、使っている人たちが広めた使い方の名前です。なので作り方も、普通のセッションに日本語で頼むだけです。

### 1回の依頼で、3つが同時に動く

例えば、1つのセッションにこう頼みます。

> 来月のキャンペーンの販売ページとメールと広告の文を、それぞれ別々にセッションを立てて同時に作って

すると Claude が3つのセッションを立ち上げ、元のセッションの下に並べて動かします。これが10月15日に入った「入れ子のセッション」です。親の下に子が並ぶ形、と思ってください。

![元のセッションの下に、販売ページ、お知らせメール、広告の文の3つが並んで同時に動いている画面](/blog/claude-2-0-kanzen-koryaku/nested.webp)

撮影用の環境（中身は架空）では、左の一覧に3つが並び、中央には仕事ごとのカードと段取り表が出ました。

### 終わると、元のセッションに報告が戻る

それぞれの仕事が終わると、元のセッションに報告が返ります。見ていないセッションの仕事が終わったときは、パソコンの通知でも知らせてくれます。なのでこちらは、元のセッションを見ていればいいんですよね。

ただし、子のセッションに「許可しますか」が出たら、その子を開いて答えます。元のセッションからの伝言では、代わりに承認できません。

![3つの仕事の状態、返事待ちの有無、保存先が表でまとまった報告の画面](/blog/claude-2-0-kanzen-koryaku/report.webp)

この表は、子のセッションの終了報告と、保存されたファイルから Claude がまとめたものです。3つを開いて回らなくても、終わったか、返事待ちか、どこに保存したかが分かります。

### ほかのセッションに、伝言も頼める

ほかのセッションが何をしたかを読んだり、メッセージを送ったりもできます。「見積もりのセッションはどういう結論になった？」「請求書のセッションに、途中で金額が変わったから伝えて」のように頼みます。

![元のセッションから別のセッションへ件名案の追加を頼み、返事が戻ってきた画面](/blog/claude-2-0-kanzen-koryaku/message.webp)

録画には、お知らせメールのセッションへ「件名の案を3つ足して」と伝言を頼む場面があります。相手が作業したあと、足した件名の報告が元のセッションに戻っています。相手が作業中なら、今の作業が一段落してから読みます。

### 一番上に置いて「返事待ちはどれ？」

私のおすすめは、マスターセッションをサイドバーの一番上にピン留めすることです。そこで「私の返事を待っているのはどれ？」と聞けば、やり取りの窓口が1つになります。

ただし、全部が見えるわけではありません。公式の説明では次の範囲です。

- 初期設定で見るのは、最近動いた20個まで
- しまった（アーカイブした）セッションは、頼まないと見ない
- クラウドで動くセッションや、ターミナルで始めたセッションは見えない

もう1つ、同時に動かすときの注意です。初期設定では、子のセッションも同じフォルダを触ります。社員3人に1枚の紙を同時に直させると混ざるのと同じなので、「仕事ごとに別のファイルに保存して」と一言添えてください。

## 私の使い方：業務ごとに5つの窓口

ここからは、私が普段どう使っているかです。私は業務ごとに、マスターセッションを5つ立てています。

![業務ごとに5つの窓口。広報、Web更新、営業・研修資料、事務、メール](/blog/claude-2-0-kanzen-koryaku/five-windows.webp)

1. 広報：YouTube や X の発信
2. Web：Web アプリと Web サイトの更新。アプリごとに子のセッションも立てる
3. 資料：営業資料と研修資料づくり
4. 事務：請求書や補助金関連の書類づくり
5. メール：返信の下書き。送るのは私

この形にしてから、毎日やることがすごくシンプルになりました。それぞれの窓口に「今やるべき仕事を進めてください」と頼みます。すると、メール、カレンダー、議事録を読んで最新の情報を取ってから、仕事を進めてくれます（先に各サービスとの連携の設定は必要です）。

もちろん、AI が判断に迷う所は出てきます。そのときは、マスターに方向性を伝えるか、その仕事のセッションに直接話しに行きます。部長に言うか、担当に直接言うか。会社と同じです。

正直なところ、以前はターミナルをいくつも並べて使っていました。でもこの使い方にしてから、自分の手で動かす日々の仕事はデスクトップアプリに移りました。公式の案内でも、たくさんのセッションを1つの窓で見るならデスクトップアプリ、プログラムで自動で動かすならターミナル、という使い分けです。

## 2つ目：新しい画面の見方

画面は、左・中央・右の3つに分かれています。

![新しい画面の地図。左がサイドバー、中央が会話、右がセッション詳細パネル、入力欄の下にモデルと確認の仕方](/blog/claude-2-0-kanzen-koryaku/screen-map.webp)

| 場所 | 名前 | 何をする所か |
|---|---|---|
| 左 | サイドバー | 仕事（セッション）を選ぶ |
| 中央 | 会話 | 頼む、答える、承認する |
| 右 | セッション詳細パネル（セッションレール） | 今の状態を見る |

右の欄が見えないときは、窓を広げるか、右上のボタンで出してください。

### 右の欄：まず「環境」と「コンテキスト」

右の欄で見るのは、2つで十分です。

「環境（Environment）」には、どのパソコンの、どのフォルダで動いているかが出ます。あとで出てくる Remote Control のスイッチもここです。

「コンテキスト（Context）」には、Claude が今抱えている情報の量がパーセントで出ます。社員で言えば、机の上がどれだけ埋まっているか、です。

![コンテキストは今抱えている情報。書類が増えると机の上がいっぱいになっていく](/blog/claude-2-0-kanzen-koryaku/context-desk.webp)

いっぱいになると、Claude が自動で会話を要約して続けます。早めに片付けたいときは「/compact」と打てば、その場で圧縮できます。話題が変わるなら、新しいセッションに移すのが基本です。

### 中央：会話の中に出てくる4つ

![会話の中に出る4つ。段取り表、まとめと次のボタン、確認、仕事の提案](/blog/claude-2-0-kanzen-koryaku/conversation.webp)

1. 段取り表：作業中、会話の一番下に計画が出ます。今どこで、次に何をするかが分かります
2. まとめと次のボタン：終わると、短いまとめと次にやることのボタンが出ることがあります
3. 確認と質問：「実行していいですか」という確認も、Claude からの質問も、会話の中に出ます
4. 仕事の提案：別にやった方がいいことを見つけると、カードで提案します。「開始」で別のセッションとして動きます

4つ目は、今のセッションでそのままやってもらう「ここで実行」も選べます。押すまでは始まりません。

### 左：お客さま別・仕事別に整理

サイドバーでは、セッションを「セクション」に分けて、お客さまごと、仕事ごとに整理できます。名前は「メール」「営業資料」のように、一目で分かるものにしてください。

### サイドチャット：作業を止めずに横から聞く

作業中に聞きたいことが出たら、Mac は「⌘＋;（セミコロン）」、Windows は「Ctrl＋;」を押します。横にサイドチャットが開きます。

![サイドチャットの画面。質問ごとにタブができ、元の会話には足されない](/blog/claude-2-0-kanzen-koryaku/sidechat.webp)

作業中の社員の手を止めさせずに、横から「今どこまで進んでる？」と聞く感じです。元の会話は読んでくれますが、元の会話には何も足しません。

逆を返せば、ここでした指示は元の仕事に伝わりません。決まったことは元の会話に書いてください。

## 3つ目：Remote Controlで、外から返事をする

Remote Control は、名前のとおりリモコンです。動いているのはパソコンの Claude で、スマホは指示を送るだけです。前からある機能ですが、新しい画面では右の欄のスイッチで入れられます。

![Remote Controlのスイッチを入れる前後と、別の端末に同じ会話が出た画面。録画では幅の狭いブラウザで表示](/blog/claude-2-0-kanzen-koryaku/remote.webp)

### 使い方は3ステップ

1. パソコンで、右の欄の「環境」にある Remote Control のスイッチを入れます
2. スマホの Claude アプリに同じアカウントでログインして、「Code」を開きます（ブラウザなら claude.ai/code）
3. そのセッションを開いて、返事や承認をします

設定で、新しいセッションを最初からつなぐこともできます。すでにそうなっている場合もあるので、スイッチの状態は確かめてください。Team と Enterprise は、先に管理者が機能を有効にする必要があります。

マスターセッションにつないでおくと、外からの指示や相談は窓口1つで済みます。子のセッションの「許可しますか」にも外から答えたいときは、その子もつなぎます。

つないだセッションは同じアカウントでログインした端末に出ます。アカウントを社員と使い回さないでください。

### パソコンは、電源につないで開いたまま

![パソコンは電源につないで開いたままに。閉じると作業が止まる](/blog/claude-2-0-kanzen-koryaku/keep-on.webp)

リモコンなので、パソコンを閉じる、電源を切る、Claude のアプリを終了する、のどれでも止まります。Claude の作業中にスリープさせない設定（Keep computer awake while Claude works）もありますが、返事待ちの間は眠ることがあります。

電源につなぎ、パソコンがスリープしない設定にして、アプリを開いたままで出かけてください。

## プランの選び方：まずはProかMax

同時に動かすほど、使う量は増えます。社員を3人動かせば人件費も3人分、と同じ考え方で、子のセッションもそれぞれ使用量を使います。

10月30日に、一番上のプランの名前が Ultra になりました。[公式の説明](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan)では、自動の確認が済んだアカウントは5時間ごとの制限がなく、週の上限は Pro の10倍です。週の上限そのものは残っています。

なので順番は、こう考えてください。

1. まずは Pro か Max で始める
2. 上限によく当たるようになったら Ultra を検討する

今の使用量は、入力欄の下の丸いしるしで見られます。料金は変わりやすいので、[公式の料金ページ](https://claude.com/ja/pricing)で確かめてください。

## 4つ目：APIクレジットを受け取る

API は、Claude を自分の会社のシステムやアプリに組み込んで使う方法です。普通は電気代と同じで、使った分だけ払います。API クレジットは、その支払いに使える「毎月届く API 専用の商品券」です。

Max は毎月100ドル分、Ultra は毎月200ドル分です。Team は座席の種類と数に応じて合算されます（上限は月500ドル分）。無料、Pro、Enterprise は対象外です。

### 使える所と、使えない所

| 使える | 使えない |
|---|---|
| 自分で作るアプリやエージェント（自分で動く AI） | Claude Code での作業 |
| Playground（API を試せる画面） | プランの上限を超えたあとの利用 |

### 受け取り方

1. ブラウザで claude.ai を開き、設定の「お支払い」へ進みます（Team は組織の設定からオーナーが行います）
2. 「API クレジット」の欄で、API 用のアカウント（Console の組織）を選ぶか、新しく作ります
3. 規約を読んで同意し、つなぎます。カードの登録は要りません

![受け取る前に確認する5つ。対象プラン、ブラウザで手続き、新規契約は7日後、つなぎ先は自分で変更不可、繰越なし](/blog/claude-2-0-kanzen-koryaku/diagram-3-credit.webp)

気を付ける所は3つです。新しく契約した人は、7日たってからでないと受け取れません。つなぎ先は自分では変えられないので、会社で使うアカウントかどうかを先に確かめます。使わなかった分は、その月の期間の終わりに消えます。

おすすめの使い道は、社内の小さな仕組みです。例えば問い合わせの返事の下書きを作る仕組みを Claude Code に作ってもらい、その API の代金をクレジットでまかないます。対象のプランの方は、まず受け取りから済ませておいてください。

## 動画のあとに変わったこと

11月7日の公開から11月22日までの更新を、公式の更新履歴で見ました。使う人に関係する主な物は次の3つです。更新が手元に届くまで、数日かかることもあります。

- 11月10日：セッションをたくさん開いていると Code の画面が固まる不具合が直りました。何本も動かす人は更新しておいてください
- 11月12日：確認の仕方が「自動」のとき、Claude が立てたセッションが、さらに別のセッションを承認なしで立てられるようになりました（こちらのメッセージ1回につき10個、同時に5個まで）。その分、使用量も増えます
- 11月20日：スマホの Claude アプリの新しい見た目が、iPhone から順番に広がり始めました。Remote Control の画面が、説明と違って見えることがあります

## 動画の補足：正確にはこうです

動画で話した言葉のうち、記事で正確に言い直した主な所を2つ書いておきます。

1. Ultra の値段：動画では「日本の公式ページだと税込みで220ドル」と話しました。11月22日に見たページの表示は月200ドル（税別）です。日本では[4月から消費税10%が加わる](https://support.claude.com/en/articles/14051822-notice-regarding-consumption-tax-jct-for-japanese-customers)ので、ブラウザで契約すると税込220ドル相当になります
2. API クレジットの超過：プランの料金に上乗せされないのは動画のとおりです。ただし API 側に自分で買った残高があると、使い切ったあとはそちらから使われます。自動チャージはその残高だけを見るので、入れているとクレジットが残っていても課金されることがあります

## よくある質問

### プログラミングができなくても使えますか

使えます。デスクトップアプリなら、ターミナルも別のソフトの準備も要りません。日本語で頼んで、確認に答える形です。

### 無料プランでも使えますか

Code は使えません。Pro 以上の有料プランか、Team・Enterprise が必要です。API クレジットの対象はさらに狭く、Max・Ultra・Team です。

### Coworkとは何が違いますか

Cowork は、プログラミング以外の仕事を長めに任せるための機能として出てきたものです。この記事で扱ったのは、同じアプリの中の Code です。Cowork 自体は [Claude Cowork の解説](/blog/claude-cowork-kaisetsu/)をどうぞ。

### 何本くらい同時に動かせばいいですか

最初は3本で十分です。増やすほど使用量も、人が確認する量も増えます。報告を読み切れる数から少しずつ増やしてください。

## 今日からの一手：3ステップ

1. 今日：アプリを更新して、練習用のフォルダで小さな仕事を1つ頼む
2. 今週：1つの依頼を3つのセッションに分けて、報告が戻る所までやってみる
3. 来週：一番時間を使っている業務に、専用のマスターセッションを1つ立てる

5つの窓口をいきなり作る必要はありません。まずは1人目の部長を、1業務に置くところからです。送信・公開・支払い・削除は人がやる、とだけ最初に決めてください。そこさえ人が持てば、手前の作業はかなり任せられます。

## そのまま使える頼み方

動画で話した使い方を、そのまま貼れる文にしました。初めての人向けに、安全のための一言も足しています。「〇〇」は自社の言葉に置き換えてください。

### マスターセッションを作る

> あなたは〇〇業務の窓口です。私が仕事を頼んだら、必要に応じて別のセッションに分けて進めてください。終わったら、結果・保存先・私が確認する所を、この会話でまとめて報告してください。送信・公開・支払い・削除はせず、下書きまでにしてください。

### 進み具合を聞く

> 今動いているセッションのうち、私の返事を待っているのはどれですか。終わったもの、進行中のもの、返事待ちのものに分けて教えてください。
