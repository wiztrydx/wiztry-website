「会社やお店の紹介に、きれいな映像を入れたい。でも撮影に行く時間も、映像の素材を買う予算もない」。そう感じている中小企業の方に向けて、撮影を一切せずに、AIだけで作った4Kの短編映像を、作品と作り方に絞ってご紹介します。

使ったのは、ByteDance（TikTok の親会社）の動画生成AI Seedance 2.5 です。4Kで書き出せるようになったので、地球の生き物と景色を描いた1分53秒の短編を1本と、使いどころを確かめる10パターンの映像を作りました。

結論から言うと、ほとんどのカットは破綻がなく、そのまま使えるレベルでした。一方で、日本語の文字、細かい手の動き、そしてコストには注意が必要です。

## 完成した作品

作品は「THE EARTH IS LIVING」という1分53秒の短編です。雲海の夜明けから始まり、象の群れ、ライオン、虎、海の中、鯨、オーロラと続いて、最後は宇宙から見た地球で終わります。

全部で24カット、すべて Seedance 2.5 の4K（1カット5秒）で作りました。実写は1カットも入っていません。

風や水の音などの環境音も、AIが映像と一緒に作っています。音楽と効果音は足していません。生成のあとに映像に手を入れたのは、カットをつなぐこと、最後の地球のカットをゆっくり流すこと、題字を入れることの3つです。音では、最後の英語のナレーション2行だけを、Gemini の音声合成で作って重ねました。

ほとんど、出てきたカットをそのままつないだだけです。私は以前、映像に関わる仕事をしていたのですが、正直なところ、電気屋さんの大画面テレビで流れている映像かと思いました。

### 10パターンの実写テスト

短編とは別に、仕事で使いそうな場面を10パターン、4Kで作りました。麺をすする女性、夜の街を歩く女性、飲み物のCM、走る車、寿司を握る手元、年配の男性の顔のアップ、腕時計、夜の街の空撮、ダンス、会議室の3人です。

いちばん驚いたのは、顔のアップでした。シワ、ヒゲ、目に入る光まで出ていて、私にはAIだと見抜けませんでした。激しいダンスや、3人が並ぶ会議室のカットでも、顔や体はほとんど崩れませんでした。

## 作り方

### 使った道具

| 役割 | 使ったもの |
|---|---|
| 映像と環境音 | Seedance 2.5（Higgsfield から使用） |
| 22カットの頼み方 | Claude Code から、Higgsfield の MCP 経由 |
| 最後の英語のナレーション | Gemini の音声合成 |
| カットのつなぎと題字 | パソコンの中の編集 |

Higgsfield は、いろいろな動画生成AIを1か所で使えるサービスです。パソコンのブラウザから使えます。24カットのうち、サイトの画面で作ったのはライオンと虎の2カットです。残りの22カットは、Claude Code（Anthropic のAI）から MCP（AIにほかのサービスをつなぐ仕組み）を通して、Higgsfield に頼んで作りました。使うモデルも料金も、サイトの画面と同じです。下の手順は、サイトの画面で作った、ライオンのカットの例です。

### 手順（ライオンのカットの例）

1. Higgsfield のサイトで、モデルに Seedance 2.5 を選びます。品質を4Kにすると、5秒で140クレジット（生成に使うポイント）と出ます。ただ、ここではまだ押しません。
2. モデルを Seedance 2.5 Draft に切り替えます。480p の低画質版の下書きで、1本15クレジットです。
3. 指示文を入れて、下書きを4本作ります。同じ指示文でも、4本とも違うライオンが出てきます。ここで見るのは動きとカメラだけで、画質はまだ見ません。
4. いちばん良い1本の「4Kで生成」を押します。1分半ほど待つと、まったく同じ動きのまま4Kになります。
5. 24カットそろったら、つないで1本にします。

### 指示文のポイント

指示文は英語で、3つのかたまりでできています。

- 絵の中身：カメラの動き、写すもの、光の向き（例：夜明けの逆光の中で吠えるライオン）
- 見た目の決まり：自然のドキュメンタリーの実写のように、自然光だけ、文字やロゴは出さない
- 音の決まり：その場の環境音だけ。音楽、声、ナレーションは入れない

見た目と音の決まりは、どのカットもほぼ同じ文です。カットごとに書きかえるのは、最初の絵の中身だけです。

### かかったクレジットと時間

| | 本数 | 1本 | 合計 |
|---|---|---|---|
| 下書き（480p・5秒） | 32本 | 15 | 480 |
| 4K（5秒） | 24本 | 140 | 3,360 |
| 短編の合計 | | | 3,840 |

作り直しは、どれも下書きの段階で済ませたので、4Kの作り直しは0回でした。10パターンの映像と合わせると、検証全体で5,555クレジットを使っています。4Kの生成は、1カットあたり1分半から2分ほどでした。

ライオンのカットで比べると、下書き4本（60）と4K 1本（140）で合計200クレジットです。最初から4Kで4本作っていたら560クレジットなので、360クレジット、6割以上を節約できました。

## ここから分かること：中小企業でも、撮影なしで4Kの映像素材が作れるようになった

### 1. 1本作れば、横・ズーム・縦の3通りに使える

4Kで作るメリットは、映像のきれいさだけではありません。

- あとからズームできる：4Kなら、2倍に寄せてもフルHD（一般的な高画質）のままです
- 縦の動画に切り抜ける：横で作った1本から、ショート用の縦動画が作れます。縦に切り抜いても、フルHDの縦動画より大きい画質が残ります

なので、横の動画はホームページやYouTubeに、縦の動画はSNSに、と1本から使い回せます。

### 2. 向いている仕事

- 会社やお店の紹介動画に入れる、景色や雰囲気のカット
- 観光や地域のPRの、イメージ映像
- 飲み物や料理など、物を見せるCMの素材
- 買ってくる映像素材の代わり

特に、飲み物のカットはスタジオで撮ったような仕上がりで、そのままCMにも使えそうでした。

### 3. まだ苦手なこと

1つ目は日本語の文字です。夜の街を歩く女性のカットでは、後ろの看板が日本語っぽいのに文字化けしていました。

2つ目は細かい手の動きです。寿司職人の手元のカットは、手のシワや濡れたツヤはリアルなのに、握り方が不自然で、ちゃんと握れていませんでした。

3つ目はコストです。4Kは5秒1カットで140クレジットかかるので、短い作品でもクレジットはすぐに減ります。

### 4. どこから始めるか

クレジットを節約するコツは、作る前の準備です。

1. 指示文をできるだけ具体的に書く
2. 人物は、映像にする前にキャラクターシート（人物の見た目をまとめた画像）にする
3. 看板や商品は、元になる画像を用意する
4. いきなり4Kにせず、480pの下書きで動きとカメラを確かめてから4Kに上げる

4つ目がいちばん効きます。下書きは4Kのおよそ9分の1の値段です。

まずは、自社の紹介に使いたい景色や物を1つ決めて、5秒の下書きを何本か作ってみてください。気に入った1本だけを4Kに上げれば十分かなと思います。
