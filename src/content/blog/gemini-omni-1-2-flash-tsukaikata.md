会社の紹介動画を作りたい。でも、撮影を頼むほどではないし、AIの使い方も分からない。そんな社長は多いかなと思います。

そこで試してほしいのが、Google の動画を作るAI「Gemini Omni 1.2 Flash」です。Google Flow というサイトを開いて、文章や画像を渡すと動画ができます。お金は0円から。毎日もらえる無料の枠で試せます。

この記事は、日本時間の11月6日の発表を受けて11月8日に公開した YouTube 動画を、初めての人が試す順に書き直したものです。料金と機能は、11月22日に公式の情報で確かめ直しました。

## この記事の要点

- 何を：文章や画像から、3〜15秒の動画を作れます。できた動画を言葉で直すこともできます
- どこで：Google Flow です。パソコンのブラウザで開き、Google アカウント（18歳以上）で使います
- いくらから：0円です。毎日50クレジット（作るための持ち点）がもらえます。最初におすすめの「360p（粗めの画質）・5秒・1本」なら5クレジットなので、10本分です
- どこから有料か：11秒以上の動画、続きを作る「延長」、あとから高画質にする「アップスケール」は有料プランです

## まず言葉を2つだけ：Flowは作業場、Omniは作る力

似た名前が出てくるので、先に整理します。

- Gemini Omni 1.2 Flash：文章や画像から動画を作るAIです。画面には「Omni 1.2 Flash」、ヘルプには「Omni Flash 1.2」と出ます
- Google Flow：そのAIを使うための作業場です。パソコンのブラウザで開きます

![Google Flowは作業場、Omniは動画を作る力](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-1-words.webp)

大工さんで言えば、Flow が工房で、Omni はそこで手を動かす職人です。社長が覚えるのは「どこを開くか」と「どう頼むか」の2つで大丈夫です。

## まず無料で、5秒の動画を1本作る

いきなり会社の紹介動画は作りません。まずは、公開しても困らない題材で5秒だけ作ります。

1. パソコンの Chrome か Edge で「Google Flow」と検索して、[公式のページ](https://flow.google.com/)を開きます。18歳以上の Google アカウントが必要です
2. 新しいプロジェクトを作ります。プロジェクトは、動画1本分の作業フォルダのようなものです
3. 入力欄の右下にある設定を開き、「動画」に切り替えます
4. モデル（使うAI）が「Omni 1.2 Flash」になっているかを見ます。別の名前なら選び直してください
5. 画質を360p（粗めの試作用）、長さを5秒、本数をx1にします
6. 使われるクレジットの数を見てから、頼みたい内容を書いて送ります

![Google Flowの設定画面で見る5か所。画質、長さ、本数で使うクレジットが変わる](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-2-settings.webp)

最初に送る文は、これで十分です。記事用に作った型なので、言葉は自社に合わせて変えてください。

> 朝のパン屋の店先。焼きたてのパンが並ぶ棚に、カメラがゆっくり寄る。明るく温かい雰囲気。人物なし。一続きのカットで。セリフなし、音楽なし。

使うクレジットは、画質と長さで決まります。10秒までなら、360pが1秒1、720p（標準の画質）が1秒3です。毎日の50は、使い残しても翌日に持ち越せません。

- 360p・5秒：1本5クレジット。50で10本
- 720p・5秒：1本15クレジット。50で3本
- 720p・10秒：1本30クレジット。50で1本

![無料の50クレジットで作れる本数の目安](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-3-credits.webp)

気をつけたいのが本数です。動画に映した画面では「720p・10秒・x2」で60クレジットと出ていました。この設定だと、1回で無料の1日分を超えます。なので、最初はx1にしてください。

## 1.2で進化したのは、この4つ

1つ目は一貫性です。一貫性とは、場面が変わっても同じ人、同じ物に見えること。渡した画像の人物や物の見た目が、前より崩れにくくなりました。

2つ目は料金です。API（プログラムから使う入口）では、720pの動画が1秒あたり約0.07ドルになり、前の版より約30%安くなりました。これは API の話で、Flow のクレジットが3割減ったわけではありません。

3つ目は長さです。1回で作れる上限が10秒から15秒に伸びました。Flow では、無料の人は10秒まで、有料プランの人は15秒までです。

4つ目は、会話で直す編集です。できた動画に「夕方にして」と話しかけて、続けて直せます。直せる長さも、有料プランなら15秒までになりました。

## 仕事で使える4つの機能

全部の機能を覚える必要はありません。仕事に直結する4つに絞ります。

![仕事で使える4つの機能。素材、フレーム、編集、セリフと文字](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-4-features.webp)

### 1. 素材：同じ人や商品で動画を作る

何ができるか。人物、商品、場所の画像を渡して、その見た目のまま動かせます。

仕事のどこで使えるか。自社のキャラクターを毎回同じ顔で出す、商品を違う場面で見せる、といった所です。

コツは、動画より先に画像をそろえることです。Flow は画像も作れます。画像モードで Nano Banana 2.1 という画像のAIを選ぶと、一度に4枚まで作れて、クレジットは減りません（1日の枚数の上限はあります）。

画像づくりのコツは3つです。

- 1枚に1人。背景は無地で、できるだけ全身
- 目印を入れる。作例では目元と口元のほくろ、椅子のハートの穴
- 年を取った姿は、元の画像を渡して「30年後」と頼む

![作例の比較。子どもと30年後の大人、新しい椅子と古くなった椅子に同じ目印が残っている](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-5-consistency.webp)

画像がそろったら、動画の設定で「素材」を選んで画像を入れます。頼む文は、カメラ、被写体（映る人や物）、動作、雰囲気の4つで考えます。

![動画の頼み方は、カメラ、被写体、動作、雰囲気の4つで考える](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-6-prompt.webp)

動画で紹介した頼み方がこちらです。父、娘、椅子、工房の4枚の画像を素材に入れています。

> 朝の工房。父が小さな椅子を丁寧に磨き、5歳の娘がそばで見ている。ゆっくり寄る。一続きのカットで。セリフなし、音楽なし。

最後の2文が大事です。「一続きのカットで」と書くと、1本1場面になりやすく、あとで編集しやすくなります。「セリフなし、音楽なし」は、人物が勝手に話し出すのを防ぐために書きます。

### 2. フレーム：2枚の画像の間をつなぐ

何ができるか。最初の画像と最後の画像を渡すと、その間の動きをAIが作ります。

仕事のどこで使えるか。動画では、脚の折れた椅子が直る場面と、工事前から工事後へ変わる台所を紹介しました。会社なら、完成イメージや、空の店内が開店の日に変わる様子に使えます。

頼み方は、設定で「フレーム」を選び、「開始」と「終了」に画像を入れて、変わり方を書きます。下の文は記事用の型です。

> 最初の画像の部屋が、最後の画像の部屋へ少しずつ変わる。カメラは固定。一続きのカットで。セリフなし、音楽なし。

![フレームの使い方。最初と最後の画像を渡す。例は脚の折れた椅子と直した椅子、工事前と工事後の台所](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-7-frames.webp)

途中の動きはAIの想像です。工事の紹介に使うなら、実際の施工の記録に見えないよう「AIで作ったイメージ」と添えてください。

### 3. 編集：言葉で直す

何ができるか。できた動画を選んで、直したい所を文章で送ると、新しい版ができます。

仕事のどこで使えるか。時間帯や天気を変える、小物を足す、といった小さな直しです。

動画で紹介した頼み方は、次の3つです。

> この動画の時間帯を夕方にして、窓から夕日が差し込むように。ほかはすべてそのままでお願いします。

> 窓の外に雪を降らせて。ほかはすべてそのままにして。

> 椅子の上に、小さな白い猫を座らせて。ほかはすべてそのままにして。

![言葉で3回直した作例。元の動画、夕方、雪、白い猫の順](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-8-edit.webp)

コツは、1回に変えるものを1つに絞ることと、「ほかはそのまま」と書くことです。Flow が前のやり取りを覚えているのは3回分までですが、前の版は履歴に残ります。失敗しても戻せます。

ちなみに、直すのにもクレジットを使います。360pの5秒なら、1回5です。

### 4. セリフと文字：日本語で伝える

何ができるか。人物に話させたり、動画の中に文字を出したりできます。

仕事のどこで使えるか。短いあいさつや、「無料見積り受付中」のような一言の告知です。

話す言葉と出す文字は、かぎかっこで囲みます。下は、動画の例を記事用に短くした型です。

> 作業着の女性スタッフがカメラに向かって、日本語で「〇〇工務店にお任せください」と話す。画面の下に日本語の文字で「無料見積り受付中」と大きく表示する。一続きのカットで。音楽なし。

動画の作例では、日本語の文字が文字化けせずに入りました。ただし、電話番号や金額のように間違えられない文字は、あとから編集ソフトで入れると確実です。

公式には、英語で頼むほうが精度が上がりやすいという案内もあります。私は分かりやすさを優先して、日本語でよいと思っています。うまくいかないときだけ、AIに英語へ直してもらえばよいかなと思います。

## 徹底検証：30年たっても同じ人に見えるか

動画の冒頭に出したのは、Gemini Omni 1.2 Flash で作った短いアニメの作例「父の椅子」です。父が作った椅子を、大人になった娘が直す話にしました。時間をまたいでも同じ人、同じ物に見えるかを検証したかったからです。

見た所は3つです。

- 女の子：大人になっても、ほくろと顔立ちで同じ人に見えます
- 父：壁の写真になっても、髪型と服が同じです
- 椅子：古くなっても、形とハートの穴が同じです

大人の娘、古い椅子、工房、父の4つの画像を渡した場面でも、4つとも動画に入りました。ここは、かなり使いやすくなったかなと思います。

自社の人や商品で作るときも、見る所は同じです。目印を先に決めておき、公開する前に顔、商品の形、文字を人が見てください。

## 1本に仕上げる順番

短い動画を何本か並べると、会社の紹介動画のたたき台になります。順番は次の5つです。

![完成までの5工程。シナリオ、画像、動画、音楽、声](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-9-flow.webp)

1. シナリオ：ChatGPT、Gemini、Claude のどれかに、話の案を3つ出してもらう
2. 画像：登場する人、物、場所を先に作る
3. 動画：1本に1カット。安い360pで候補を作り、良い物を選ぶ
4. 音楽：あとから足す。動画では Google AI Studio の Lyria 3.5（有料）で作る画面を紹介しました
5. 声と編集：ナレーションを足してつなぐ。編集は Google Vids でもできます

シナリオは、ゴール、条件、時間の経過の3つを入れて頼みます。動画で紹介した文を、記事用に一部書きかえました。

> ゴール：45秒以内で、動画生成AIで作れる短いアニメのシナリオを3案出してください。条件：セリフがなくても伝わるシナリオにしてください。時間の経過：同じ人や同じものが、時間をまたいで残るシナリオにしてください。

話の続きを作りたいときは、有料プランの「延長」もあります。AIが見るのは直前の10秒だけなので、それより前の人物や出来事は、頼む文にもう一度書きます。

声の作り方は [Gemini 3.8 TTSの使い方](/blog/gemini-3-8-tts-tsukaikata/) に、短い物語の組み立て方は [AIで2分のドラマを作ったときのコツ](/blog/ai-short-drama-2fun/) に書いています。

## お金と、12月5日に終わるモデル

無料で足りなくなったら、Google AI Plus、Pro、Ultra の順に月のクレジットが増えます。有料プランなら、安い360pで何本か作り、うまくできた物だけをフルHDにアップスケールできます。こうすると費用を抑えられます。4Kへのアップスケールは Ultra だけです。

料金と枠は変わりやすいので、この記事には表を載せません。[日本の料金のページ](https://gemini.google/jp/subscriptions/?hl=ja)と[Flowのクレジットのページ](https://support.google.com/flow/answer/16526234?hl=ja)で確かめてください。

もう1つ、日付を覚えてください。12月5日に、Flow で次の3つの提供が終わります。

- Omni 1.1 Flash
- Veo 3.1 Fast
- Veo 3.1 Quality

![Google Flowのモデル選択画面。3つに12月5日に提供終了と表示され、Veo 3.1 Liteには表示がない](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-10-models.webp)

Veo 3.1 Lite は終了の対象に入っていません。とはいえ、これから覚えるなら Omni 1.2 Flash からでよいかなと思います。

## 会社で使う前に、4つ確認する

![会社で使う前の4つの確認。入れる物、設定、権利、見せ方](/blog/gemini-omni-1-2-flash-tsukaikata/diagram-11-check.webp)

1. 入れる物：お客様の顔、住所、書類、未発表の商品は入れない
2. 設定：Flow の画面上部の「その他」に「Google Flow の改善に協力する」があれば、オフにする。会社のアカウントは、管理者に設定と規約を確かめる
3. 権利：使ってよい写真だけを入れる。仕事での利用は、Google の利用規約も読む
4. 見せ方：AIの映像を、実際の実績、社員、お客様の声のように見せない

設定がオンだと、入れた内容がサービスの改善に使われ、人が確認することもあります。会社のアカウントでも学習に使われる場合があると、Google の管理者向けの説明に書かれています。

## 動画の補足：正確にはこうです

- 「安く作れる」は API の話です。Flow では、前の版の Omni 1.1 Flash と比べて、設定によって増減します。720p・10秒を1本作る分は15から30クレジットに増え、360p・5秒を言葉で直す分は40から5に減りました
- 「最大3ターン」は、Flow が前のやり取りを覚えている範囲です
- 12月5日に終わる Veo 3.1 は Fast と Quality です。Lite は含まれません

## よくある質問

### スマホでも使えますか

初めての方にはパソコンをすすめます。「フレーム」と「延長」は、ウェブ版の機能だからです。

### 無料なのに作れない時間があります

Google のヘルプには、有料プランでない人は日本時間の23時から翌2時ごろに動画を作れない場合がある、とあります。昼間に試してください。

### 失敗した分のクレジットは戻りますか

生成そのものに失敗した分は、1時間以内に戻ると案内されています。思った絵と違っただけの分は、戻る前提にしないでください。

### Google Vids や Gemini アプリでも使えますか

使えます。Google Vids には[無料の枠](https://support.google.com/docs/answer/15609411?hl=ja)がありますが、作った映像は Vids の中で使う決まりです。Gemini アプリの動画づくりは、個人なら有料プランが必要です。複数を同時に作れて、あとから直しやすいので、作り込むなら私は Flow をすすめます。

### AIで作ったことは分かりますか

SynthID という、目に見えない印が入ります。ただ、見た人には分かりません。実写と間違われそうな映像には、自分で一言添えてください。

### 作業を丸ごとAIに任せられますか

Claude Code や Codex という、作業をしてくれるAIを使う方法もあります。その場合は API の料金が別にかかります。進め方は [Claude Codeに予算1,500円でCMを作らせた記事](/blog/claude-code-1500yen-cm/) が参考になります。
