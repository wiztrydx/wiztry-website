「商品を紹介する動画を作りたい。でも編集ソフトは触れないし、曲を頼む予算もすぐには出せない」。そう感じているお店や中小企業の方に向けて、私が架空のレモンソーダで約24秒の商品紹介ミュージックビデオ（MV）を作った手順を全部書きます。

結論から言うと、編集ソフトを一度も開かずに、歌った瞬間に歌詞の文字がポンと出るMVができました。音と映像の動きをピタッと合わせることを「音ハメ」と呼びます。頼んだ先は Claude Code（Claudeのデスクトップアプリで使える、パソコンの中で作業してくれるAI）です。ただし曲は Suno（歌入りの曲を作るAI）、画像と動画は別の生成AIで作っていて、素材の費用が約487円かかりました。時間は、曲から完成まで直しを含めて約2時間です。

11月5日に公開したYouTube動画の内容を、料金と規約を11月6日に公式ページで確かめ直して書き直しました。動画の画面に出したプロンプト（AIへの依頼文）を全文載せています。

## この記事の要点

- 編集ソフトは開いていません。文字の動きとつなぎは Claude Code と、無料の道具 HyperFrames（ハイパーフレームズ）で作りました
- 流れは「曲→素材→時刻の分析→編集」の4ステップです
- 肝は時刻です。Suno MCP で拍と歌詞の時刻を出して、声だけの音で確かめ直します
- 素材の費用は約487円でした（Claude と Suno の月額は別）。動画の単価は11月7日までの割引で、11月8日からは合計約1,592円になります
- Suno の曲を商用で使うなら、有料プランの間にダウンロードした曲を使います

## 動画の補足：正確にはこうです

動画の中の言い方と、制作の記録や公式の案内が違う所があります。この記事は記録と公式のほうで書いています。

1点目。曲の作り方です。動画は Suno MCP で曲を作る流れで話していますが、完成MVの曲は11月4日に Suno のWeb画面で作りました。その時点では Suno MCP がまだつながらなかったからです。翌11月5日につながったので、Claude Code から頼んで2曲できるところまで確かめました。ただし、これは完成MVの曲とは別の曲です。完成MVの時刻も、曲の音そのものから測った値で、Suno MCP の時刻は11月5日に同じ曲で出して比べました。なので、この記事は「このMVを Suno MCP で作った話」ではなく、「Suno MCP をつないで作る手順」として読んでください。

2点目。動画で「実際のプロンプト」と読んだ文は、手順を1つの文にまとめたものです。完成MVはこの文を1回送ってできたものではなく、私の直しを受けて5版目で仕上げています。動作を確かめた記録があるのは、プロンプト1の「くわしく頼むなら」の文です。ほかの文は動画の言葉のまま（プロンプト3だけは動画で説明した流れを文にしたもの）で、どれも試していません。話し言葉なので、自分の言葉に変えて大丈夫です。

3点目。画像のモデルです。動画では「GPT Image 2.6」と言っていますが、完成MVの画像35枚は、11月4日に GPT Image 2.5 で作りました。プロンプト2の文に「GPT Image 2.6を使って」とあるのは動画と同じ文だからです。モデルの名前は、読者の方がそのとき使いたいものに書きかえてください。

4点目。「必要なのはClaudeとSunoの有料プランだけです」と話していますが、画像と動画には OpenAI と fal の APIキー（外のAIを使うための鍵）と、その利用料も要ります。

5点目。費用です。動画の「490円」は約487円を丸めた数で、画像と動画に効果音の約3円を足した合計です。「Sunoの有料プランが月額8ドル」は年払いのときの月額で、月払いなら月10ドルです。

6点目。時間です。「大体30分」は素材を生成した時間です。曲から完成までは、直しの往復を含めて約2時間でした。「手を動かした時間は2〜3分」は記録で測れないので、この記事では数字を挙げません。曲を選ぶ、缶を選ぶ、直しを頼む、という人の判断は入っています。

7点目。商用の条件です。動画は「有料プランで作成した曲」と話していますが、規約の言い方は、有料プランの間にダウンロードした曲です。

8点目。「お申し込み後の承認制」と話していますが、公式に「承認制」という言葉はありません。公式にあるのは「Get early access」（早期アクセス）の申し込みです。

9点目。「1コマ単位」です。完成MVは1秒60コマで書き出したので、1コマは約0.017秒です。YouTubeの本編は1秒30コマなので、本編の中のMVは2コマに1枚になります。この記事の上に置いたデモ動画は、1秒60コマのままです。

10点目。「Claudeにダウンロードしてもらいました」と話していますが、完成MVの曲は Suno の画面から保存しました。Suno MCP にもダウンロードの道具（audio-download）はありますが、11月5日の確認では動かしていません。

なお、この動画は案件ではなく、費用は全部自腹です。

## 言葉の整理：Suno MCP と HyperFrames

先に言葉を4つだけ整理します。

Suno MCP は、Claude Code と Suno をつなぐ線です。MCP は、AIに外の道具を使わせるための共通の差し込み口と考えてください。Suno MCP をつなぐと、Claude Code の会話の中から曲を作ったり、曲の拍を読んだりできます。公式の案内ではベータ版です。

HyperFrames は、HeyGen社が公開している無料の道具です。ホームページと同じ仕組みで動画を作るので、Claude Code が文字の動きを1文字ずつ書けます。入れ方は [企業CMの記事](/blog/claude-code-motion-graphics-cm/) に書きました。

Demucs（デムクス）は、1つの曲を声・ドラム・ベース・その他に分ける道具です。Claude Code に頼むと、自分で入れて動かしてくれます。

拍は曲の「ワン、ツー」の1打ちです。小節は、その4拍のまとまりです。今回の曲は1分間に約149拍の速さでした。

| 必要なもの | 中身 |

| Claude の有料プラン | Pro 以上。公式の料金ページの表示で月払い20ドル（税の扱いは地域で変わります）。無料プランでは Claude Code は使えません |
| Suno のプラン | 商用で使うなら有料プラン。Pro は年払いなら月8ドル、月払いなら月10ドル |
| Suno MCP | ベータ版。早期アクセスの申し込みが要ります |
| OpenAI の APIキー | 画像に使います。使った分だけ支払います |
| fal の APIキー | 動画と効果音に使います。使った分だけ支払います |
| 無料の道具 | HyperFrames と Demucs など |

Suno MCP そのものは、公式の FAQ に無料プランを含むすべてのプランで動くと書かれています。曲を作るとプランのクレジット（曲を作るときに使う回数券のようなもの）を使います。逆を返せば、試すだけなら無料プランでも入口には立てますが、商用で使う曲は有料プランの間にダウンロードしたものだけです。

APIキーは、チャットに貼らないでください。入れ方は [1,500円のCMの記事](/blog/claude-code-1500yen-cm/) で解説しています。

作り方の全体はこの4ステップです。

## STEP1：曲を作る

### Suno MCP をつなぐ

まず Suno の [公式ページ](https://suno.com/mcp) で「Get early access」から申し込みます。申し込みのフォームには、24〜48時間以内に連絡が来ると書かれていました（11月5日に確認）。

先に、素材と動画が入るフォルダを1つ作って、Claude Code で開いておきます。つなぐのは2段階です。ターミナル（パソコンに文字で命令する画面）にこの1行を入れます。`claude` のコマンドが見つからないときは、下のプロンプト0を Claude Code に貼って聞いてください。

```
claude mcp add --transport http suno https://api.suno.com/mcp
```

そのあと Claude Code で `/mcp` を開いて、Suno にサインインします。APIキーは要りません。サインインのあとに新しい会話を始めると、Suno の道具が使えるようになります。

![Suno MCPのつなぎ方。申し込む、ターミナルに1行、/mcpでサインイン、新しい会話で使う](/blog/claude-code-suno-mcp-otohame-mv/diagram-3-connect.webp)

つなぎ方が分からないときは、Claude Code に次の文を貼れば順番に教えてくれます。動画の画面に出した文です。

プロンプト0：Suno MCP をつなぐ（最初に1回だけ）

> Suno MCP を Claude Code につなぎたいです。公式ページ（https://suno.com/mcp）を読んで、つなぎ方を順番に教えてください。

まだつながらない方も、止まらなくて大丈夫です。歌詞だけ Claude に書いてもらって、Suno のWeb画面に貼っても曲を作れます。完成MVの曲は、実際にこの形で作りました。

### 歌詞と曲を1つのプロンプトで頼む

つながったら、歌詞も曲も1つのプロンプトで頼めます。

プロンプト1：曲を作る（動画と同じ文）

> 架空のレモンソーダ『シュワリ』という商品の、30秒くらいの商品紹介ソングを、Suno MCPで作って。曲調は早口のラップ形式で、ビートが響くような感じで。歌は1拍目からいきなり歌い始めて。歌詞の中に、プシュだったり、カランだったり、シュワ、ゴク、ハーみたいな音の言葉を入れてください。あとは、歌詞の中に数字も多めに入れてください。歌詞は、Sunoに渡す用はひらがな、画面に出す用は漢字で、歌詞は2パターン作って。

くわしく頼むなら、売りとテンポまで決めたこの文です。11月5日に、この文で歌詞2つから2曲できるところまで確かめました。

> 架空のレモンソーダ『シュワリ』の、30秒くらいの商品紹介ソングを、Suno MCPで作って。早口のラップで、150 BPMくらい。重低音。歌詞は1行1小節で、歌は1拍目からいきなり始めて。売りは、強い炭酸、レモン果汁5パーセント、砂糖半分、1本20キロカロリー。プシュッ、カラン、シュワー、ゴクッ、プハー、みたいな音の言葉を入れて、その前後は少しだけ間を空けて。歌詞は、Sunoに渡す用はひらがな、画面に出す用は漢字で、2つ作って。

コツは3つです。

1. プロンプトの中に音の言葉を入れる。プシュッやゴクッのような言葉は、音ハメにぴったりです
2. 歌詞に数字を入れる。5%や20kcalのような数字は、こういう動画だと目に残ります
3. 歌詞はひらがなで渡す。漢字のまま渡すと、たまに読み間違いが起きます。画面に出す文字は漢字のままで大丈夫です

3つ目が地味に効きます。Suno に渡す歌詞と画面に出す歌詞を分けておくと、歌は正しく読まれて、画面は読みやすくなります。

### 2曲を聞き比べて、1曲選ぶ

1回頼むと2曲できます。11月5日の確認では、クレジットは1回で10でした。曲そのものは10秒前後で完成します（8.7〜10.2秒）。ただ、その前に Claude Code が歌詞を考える時間が約3分かかりました。

音は会話の中には返ってこないので、再生ページのリンクを開いて自分の耳で聞きます。聞き比べて、歌詞がはっきり聞き取れる方を選んでください。完成MVの曲を選んだときも、最後の決めの言葉まで歌い切っている方を選びました。

長さは思いどおりにならないことがあります。私の記録はこうでした。

| 頼み方 | できた長さ |
|---|---|
| 長さの指定（duration）を30秒で付けた | 29.92秒と29.6秒 |
| 曲調の文に「32秒」と書いただけ | 57.92秒と54.76秒 |
| Web画面で作った完成MVの曲 | 40.92秒 |

「30秒くらい」と頼んだときは、Claude Code が自分で長さの指定を付けてくれました。付かないと長くなるので、長めに出てきたら、使う所だけ切れば大丈夫です。完成MVは41秒の曲の前半22.4秒を使って、最後をフェードで消しました。

### 商用で使うときの注意

Suno の曲を商用で使うなら、有料プランの間にダウンロードした曲を使ってください。Suno の利用規約では、有料プラン（Pro と Premier）の間に、プランのダウンロード枠の範囲でダウンロードした曲を、規約の条件のもとで商用に使えるとされています。無料プランとベーシックは、個人の非商用の利用だけです。

ダウンロードには回数の枠があります。私の Pro プランは月20回でした。完成MVの曲を含む2曲をダウンロードして、残りは18回です。対象のダウンロードの権利は、解約やダウングレードのあとも続くとされています。

## STEP2：画像と動画の素材を作る

曲が決まったら、映像の素材です。最初に缶のデザインを決めます。

プロンプト2：缶のデザインを決める（動画と同じ文）

> GPT Image 2.6を使って、『LEMON SODA』と書いた、おしゃれなステッカーが描かれた缶を、プロのデザイナーが考えたデザインで3案作って。実在する企業のロゴは入れないでください。

モデルの名前は、そのとき使いたいものに書きかえてください。完成MVは GPT Image 2.5 で作りました。

![AIが作った架空の缶の3案。果物の輪切りの丸い印、紺のラベル、水しぶきの形のステッカー](/blog/claude-code-suno-mcp-otohame-mv/diagram-4-can-3an.webp)

3案から、右の水しぶきの形のステッカーを選びました。

ここからが大事です。決めた缶の画像を、全部のカットで参照させます。これをしないと、カットごとに商品の見た目や形が変わってしまうことがあります。実際に私も、参照させずに作った3枚に別の缶が混ざりました。

![缶の参照の比較。参照なしで作ると青い別の缶が混ざり、決めた缶を参照すると同じデザインの缶が出る](/blog/claude-code-suno-mcp-otohame-mv/diagram-5-sansho-hikaku.webp)

次に各カットの画像と、動きが欲しい所だけの動画を作ります。下の文は動画では読んでいない文で、説明した流れをそのまま頼める形にしました。

プロンプト3：画像と動画の素材を作る（動画では読んでいない文）

> 決めた缶の画像を、全部のカットで参照してください。歌詞に合わせてカットの一覧を作って、各カットの画像を作ってください。動きが欲しいところだけ、FLUX 3 Maxで5秒の動画にしてください。缶やレモン、人の切り抜き素材も作ってください。作る前に、何枚・何本でいくらかかるかを教えて、私の確認を待ってください。

完成MVの素材はこうでした。

- 画像35枚：缶の3案、各カットの18枚、作り直し3枚、切り抜き11枚
- 動画11本：FLUX 3 Max で、720p・5秒
- 効果音10本：缶を開ける音や氷の音など。ElevenLabs の効果音を fal 経由で使いました

OpenAI と fal の APIキーを使って、Claude Code に自動で作らせています。素材の生成そのものは約30分でした。「作る前に、何枚・何本でいくらかかるかを教えて、私の確認を待ってください」の一言は入れておいてください。お金が動く操作の前に止まってもらうためです。

画像を作るときに、缶やレモン、人の切り抜きも作っておくのがおすすめです。拍に合わせて、画面にポンと出せるからです。

![切り抜きの素材の一覧。缶、レモン、氷、角砂糖と、AIで生成した架空の人物](/blog/claude-code-suno-mcp-otohame-mv/diagram-6-kirinuki.webp)

写っている人物は全員、AIで生成した架空の人物です。画像と動画の詳しい作り方は、[1,500円のCMの動画](https://youtu.be/qvVKQaQVbuo) と [その記事](/blog/claude-code-1500yen-cm/) で解説しています。

## STEP3：曲の時刻を分析する（ここが本題）

歌った瞬間に文字を出すには、「何秒に何の文字を歌ったか」が分からないといけません。ここが今回の動画のメインです。

### Suno MCP で時刻を出す

Suno MCP を使うと、ビートの位置と、歌詞のほぼ1文字ずつの時刻まで出してくれます。これだけでも、ミュージックビデオはかなり作りやすくなりました。

![Suno MCPで取れるもの。曲、拍と小節の頭、歌詞の時刻。声だけ・ドラムだけの音は取れない](/blog/claude-code-suno-mcp-otohame-mv/diagram-7-mcp-can.webp)

プロンプト4：音の時刻を出して、確かめる（動画と同じ文）

> この曲のビートと拍、歌詞の時刻を、Suno MCPで出してください。その後、声だけの音に分けて、1文字単位でずれていないかを確かめて、1コマ単位で時刻を直してください。

足すと、結果を目で確かめられる1文です。

> 結果は、声の模様の画像に重ねて見せてください。

11月5日に動かした結果を、3つ書いておきます。

1. 解析と歌詞の時刻に、クレジットは使いませんでした
2. 1回目は「処理中」が返って、1分ほどで取れました
3. 歌詞の時刻は1〜4文字ずつで返ります。86〜87%は1文字です

### Suno MCP の時刻だけだと、微妙にずれる

ただし、Suno MCP の情報だけだと、微妙に音がずれることがあります。完成MVの曲で、Suno MCP の時刻と、曲の音から測った時刻を比べました。

| 比べたもの | 差 |
|---|---|
| 拍 | 平均0.018秒・最大0.024秒 |
| 小節の頭 | 14個全部が同じ拍 |
| 歌詞（言葉の頭） | 平均0.046秒・最大0.137秒 |
| 歌詞（1音ずつ） | 平均0.046秒・最大0.222秒 |

拍はかなり合っています。歌詞も、行や言葉の単位で文字を出すなら下書きに使えます。一方で1音ずつ弾ませるなら、同じ目盛り（16分音符の刻み）に入ったのは108音中71音で、3分の1は目盛りが違いました。

ずれ方には2つの癖がありました。1つ目は、「まる」「でも」「けた」のように2文字まとめて返る所で、頭が遅れることです。2つ目は、「シュ」が息の音の始まりを指すので、拍より約0.1秒早く出ることです。2つ目は誤りというより、測り方の違いです。

### 声だけの音に分けて、Claude Code に確かめさせる

なので、Claude にダブルチェックをしてもらいます。やり方は、声とBGMを分けて、それぞれを分析させるだけです。分ける作業も Claude Code が自分でやってくれます。

![時刻は2段階で決める。Suno MCPで出す、声だけに分ける、1文字ずつ確かめる、1コマ単位で直す](/blog/claude-code-suno-mcp-otohame-mv/diagram-8-double-check.webp)

Suno MCP には、声だけの音を取り出す専用の道具はありませんでした。曲を作る道具の説明には、手持ちの曲から声やドラムを抜き出す作り方が書かれていますが、私は試していません。今回は手元で分けています。完成MVでは、ドラムだけの音から拍を測り、声だけの音に歌詞の読みを当てはめて1音ずつの時刻を出しました。そのうえで、声の模様の画像を1行ずつ目で確かめて、3か所を直しています。

下の画像がその実物です。黒く濃い所が声で、縦の線が拍、下の数字が秒です。

![声の模様に1音ずつの文字と秒数を重ねた画像。1行目のぷしゅっあけたらはじまると2行目のれもんそーだしゅわり](/blog/claude-code-suno-mcp-otohame-mv/diagram-9-oto-jikoku.webp)

時刻はまず Suno MCP から取得して、Claude でもう一度確かめる。これを覚えておいてください。

## STEP4：HyperFrames で動画を編集する

時刻がそろったら、最後に Claude Code に動画の編集とモーショングラフィックス（文字や図形に動きを付けること）を頼みます。使う道具は HyperFrames です。

プロンプト5：動画を編集する（動画と同じ文）

> HyperFramesを使って、完璧に音に合わせたミュージックビデオ風の編集をしたい。素材と音を歌詞に合わせて並べた後、先ほど分析した時刻を使って、ミュージックビデオ風に歌詞を1文字か2文字ずつ入れていってください。文字のアニメーションなんですけども、歌った瞬間にポンと弾ませるようにしてください。
> 文字を入れるときには、缶やグラスなどの主役は隠さないように、左右に分けたり、斜めに置いたりして、文字の大きさには大小をつけて入れていってください。CMの最後は曲がフェードで消えて、無音で締めのページを1.5秒ぐらい流してください。

足すと効く1文です。完成MVでも、最初はエフェクトが強すぎて見づらかったので、同じ趣旨の直しを頼みました。

> 画面全体のエフェクトは控えめにしてください。

このプロンプトのコツは4つです。

1. 文字は1文字か2文字ずつ出す。1行まとめて出すより、歌に合わせて出していくほうが音ハメが気持ちよく見えます
2. 文字で主役を隠さない。文字を大きくしても、後ろが何の映像か分かる場所に置きます
3. 最後は音をだんだん小さくして、無音のカットを入れる。CMっぽく締まります
4. 作ったあとに、Claude に自分でチェックさせる

1つ目と2つ目は、見比べると分かりやすいです。左が直す前の版、右が完成です。同じ秒のコマです。

![文字の出し方の比較。直す前は言葉ごと真ん中に出て缶のロゴを隠している。完成は1〜2文字ずつ空いた所に出ている](/blog/claude-code-suno-mcp-otohame-mv/diagram-10-moji-hikaku.webp)

文字の大きさにも差をつけています。「強」は大きく「い」は小さく、という具合です。主役の近くは小さく、空いている所はドーンと大きく置きました。

### 最後に Claude 自身に確かめさせる

ここまでで終わらせず、最後のチェックを頼みます。

プロンプト6：最後に確かめる（動画と同じ文）

> 最後に編集が終わったら、全部の文字が歌った瞬間に出ているか、音とぴったり合っているのか、そして文字の位置や後ろの映像がずれていないか、だったりも0.1秒ごとの一覧で確かめてください。

くわしく頼むなら、こう足します。

> 全部の文字が、歌った瞬間に出ているか、声の模様とその瞬間のコマを並べた表で確かめてください。おかしいところを見つけたら、自分で直してください。

完成MVでは、こんな確認表を作ってもらいました。上が声の模様で、赤い線は文字が一番大きく弾む瞬間です。下がその瞬間の完成のコマです。

![音ハメの確認表。声の模様の赤い線と、その瞬間に文字が出ている完成のコマが線でつながっている](/blog/claude-code-suno-mcp-otohame-mv/diagram-11-kakunin-hyo.webp)

こちらは0.1秒ごとの一覧です。文字が主役を隠していないか、後ろの映像が何か分かるかを見ます。

![0.1秒ごとに並べた完成MVのコマの一覧](/blog/claude-code-suno-mcp-otohame-mv/diagram-12-ichiran.webp)

このチェックで、ページの切り替えに前の文字が残る所や、文字が笑顔の顔にかかりかける所が見つかって、直してもらいました。84個の文字すべてで、その音を歌った瞬間のコマに文字が出ていることも確かめています。

正直なところ、AIは音を耳で聞けません。確かめているのは波形や画像です。気持ちよくハマっているかの判断は、最後に自分の目と耳で通しで見てください。

## よくある質問

### Suno MCP がつながりません

ベータ版で、早期アクセスの申し込みが要ります。[公式ページ](https://suno.com/mcp) の「Get early access」から申し込んでください。待つ間は、歌詞だけ Claude に書いてもらって、Suno の画面に貼れば曲を作れます。

### 指示のとおりに歌ってくれません

早口のラップ、1行1小節、音の言葉の前後の間は、指示しても効かないことがありました。2曲を聞き比べて、近い方を選んでください。テンポも文で頼むだけなので、150 BPM（1分間に150拍の速さ）と書いて158.4になった曲もありました。

### 歌詞の文字が、歌とずれます

プロンプト4のように、声だけの音で確かめて直してもらってください。ずれている所は「シュワリの文字を0.1秒早く」のように、言葉と秒数で頼むと直りやすいです。

### カットごとに缶のデザインが変わります

最初に決めた缶の画像を、毎回参照させてください。

### 同じ曲と映像はできますか

できません。生成は毎回結果が変わります。同じ流れで、同じくらいのものを目指す手順です。
