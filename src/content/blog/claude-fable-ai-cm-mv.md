「お店のCMを作りたい。でも撮影も制作会社への依頼も、うちの規模では難しい」。そう感じている中小企業の方に向けて、AIに30秒のCMとミュージックビデオを作らせた結果を、作品と作り方に絞ってまとめます。

使ったのは、Anthropic が11月9日に出した Claude Fable 5.2 です。指示文は1本の作品につき1回だけ。シナリオ、画像と動画の生成、ナレーション、編集までを Claude に任せました。

結論から言うと、70点から80点くらいのCMのたたき台が、1回の指示とAIだけで作れるようになっています。ただし、音と細かい破綻は、最後に人が確かめる必要がありました。

## 完成した作品

できたのは、30秒のCMが3本と、同じ1曲で作ったミュージックビデオが3本です。CMの題材は、どれも架空のお店です。3本とも、シナリオとカット割りは同じ Claude Fable 5.2 が考えています。題材は1本ずつ違い、映像を作る動画生成AIも1本ずつ変えました。

### ラーメン屋のCM「湯気と月」（Seedance 2.5）

![夜のラーメン屋のカウンターで、ベージュのコートの女性がラーメンをすすっている場面。AIで作った架空のお店のCMの1コマ](/blog/claude-fable-ai-cm-mv/cm-ramen.webp)

夜の路地のラーメン屋に女性が入り、店主が一杯を出して、女性がすする30秒です。私が3本の中でいちばん良いと思ったのはこの1本で、ラーメンを食べたときの表情と自然さが頭一つ抜けていました。

### パン屋のCM「こむぎと灯」（Kling 4.0）

![パン屋の店主の女性が、紙袋に入れた食パンを女の子に手渡している場面。AIで作った架空のパン屋のCMの1コマ](/blog/claude-fable-ai-cm-mv/cm-pan.webp)

朝のパン屋で生地をこね、焼き上がった食パンを親子に手渡すCMです。動きが少ない場面が多いぶん、破綻がなく、とても自然に見えました。

### お茶農家のCM「しずくと若葉」（Gemini Omni 1.2 Flash）

![茶畑の見える縁側で、年配の女性と母親と女の子が湯のみでお茶を飲んでいる場面。AIで作った架空の茶園のCMの1コマ](/blog/claude-fable-ai-cm-mv/cm-ocha.webp)

霧の茶畑で若葉に触れ、縁側で家族がお茶を飲むCMです。茶畑のような自然の絵は、ぱっと見でとてもきれいでした。一方で、人の顔や髪の質感は整いすぎていて、逆にAIだと分かりやすいと感じました。

ミュージックビデオは、Suno AI で作った1曲を Claude に渡して、同じ3つの動画生成AIで1本ずつ作らせました。歌詞の文字が、走る人の後ろを通っていく編集も入っています。こちらは動画の2分16秒あたりからご覧ください。

## 作り方

### 使った道具

| 役割 | 使ったもの |
|---|---|
| 指揮役（シナリオ・生成の指示・確認・編集） | Claude Fable 5.2（Claude Code から使用） |
| 動画生成AIの窓口 | Higgsfield（いろいろな動画生成AIを1か所で使えるサービス） |
| 映像を作るAI | Kling 4.0、Seedance 2.5、Gemini Omni 1.2 Flash |
| 曲とBGM | Suno AI（ミュージックビデオの曲と、ラーメン屋・お茶農家のCMのBGM） |

Claude Code は、パソコンの中でファイルを作ったり、編集の道具を動かしたりしてくれる Claude の使い方です。動画の生成だけなら普段の Claude の画面からでもできますが、今回は作ったあとの編集まで一気に任せたかったので、Claude Code から使いました。

### 手順は3つ

1. Claude と Higgsfield をつなぐ。Claude の画面の「カスタマイズ」から「コネクタ」を開き、「カスタムコネクタを追加」で名前とアドレスを入れて、画面の通りに連携します。このつなぐ仕組みを MCP と呼びます。APIキー（外のサービスを使うための合言葉のような文字列）は要りません。
2. Claude に頼む。指示文はとてもシンプルで、ざっくり言うと「30秒のCMを作ってください」と「この歌で30秒のミュージックビデオを作ってください」の2種類です。
3. 待つ。

指示文に書いたのは、次の3つだけです。

- 作るもの
- 使ってよいクレジット（Higgsfield で生成に使うポイント）の上限
- 納品する前に自分の目で確かめて、直してから私に渡すこと

### かかった時間とクレジット

CM2本とミュージックビデオ3本の5本を同時に進めさせたところ、1本あたり37分から54分で、5本とも1時間かからずにできあがりました（パン屋のCMは、前の日に同じやり方で作ったものです）。頼んだあと私はご飯を食べていて、その間に仕上がっていました。

30秒1本に使ったクレジットは次の通りです。

| 映像を作るAI | CM | ミュージックビデオ |
|---|---|---|
| Kling 4.0 | 147 | 188 |
| Gemini Omni 1.2 Flash | 204 | 180 |
| Seedance 2.5 | 639 | 698 |

Kling 4.0 と Omni Flash はほぼ同じで、Seedance 2.5 はその3倍以上でした。画質がいちばん高かったぶん、値段もいちばん高いという結果です。なお、Claude から Higgsfield を使うときは、どのプランでも生成のたびにクレジットを使います。

### 仕上げに、言葉で頼んで直したところ

できあがった作品を見て、気になる所は言葉で頼んで直してもらいました。直したのは、パン屋のCMの音楽と1カット、ラーメン屋のナレーションの声（Gemini の音声合成に差し替え）、ミュージックビデオの歌詞の文字の入れ方、全体の色味です。この記事の画像は、色味を整えたあとの完成版から切り出しています。

## ここから分かること：中小企業でも、CMのたたき台が作れるようになった

### 1. AIが「制作の担当者」を務められるようになった

これまでAIで動画を作るときは、カットをたくさん作らせて、良いところを抜き出してつなぐ作り方が普通でした。私もそうしていました。

今回の Claude Fable 5.2 は、必要なカットを逆算して作り、作り直したのは数カットだけで、できたカットをほぼ全部使って1本にまとめています。歌に合わせて文字を1文字ずつ出し、大きさや色を整え、動く人の後ろを通す編集も、言葉で頼むだけでやってくれました。正直なところ、私が自分でやったら、数倍のクレジットか、数十倍の時間がかかった作業だったかなと思います。

### 2. 向いている仕事

- お店や商品の紹介CMのたたき台づくり
- 制作会社に頼む前に、イメージをそろえるための試作
- SNSや店頭のモニターで流す短い動画
- 何パターンも作って、方向性を選びたいとき

なので、「まず形にして、みんなで見ながら決める」使い方には、もう十分に使えるかなと思います。

### 3. まだ苦手なこと

1つ目は音です。Claude は音を耳で聞けません。なので、ナレーションのイントネーションが自然かどうかは分かりません。今回えらいと思ったのは、Claude 自身がそれを分かっていて、納品のときに「声は耳で聞いていません。一度人間の耳で確かめてください」と書いてきたことです。実際に聞くと、一部のナレーションは微妙でした。

2つ目は、細かい場面のつじつまです。ラーメン屋のCMでは、最初のカットに無かった看板が、最後のカットには付いています。30秒の間に看板が付いたことになり、このままCMとして使うと問題になります。Claude は動画を1本の流れとしてではなく、切り出したコマで確かめているので、こういう所を見落とすことがあります。

もう1つ、頼んでいないことは出てきません。ミュージックビデオは世界観がそろっていて歌詞とも合っていましたが、絵で圧倒するようなカットは少なめでした。私がそこまで頼んでいなかったからです。ここは、人や制作会社に頼むときと同じだと思います。

逆を返せば、最後に人が確かめるのは「音」と「細かい破綻」の2つに絞れる、ということです。

### 4. どこから始めるか

おすすめは、何パターンか作らせて、ピンとくる映像を選んでから仕上げるやり方です。試すのは Kling 4.0 か Omni Flash、仕上げの1本は Seedance 2.5、という使い分けがいいかなと思います。動きが少ないCMなら、Kling 4.0 のまま仕上げても大丈夫かもしれません。

まずは1本、自社のお店や商品を題材にして、Claude に30秒の動画を頼んでみてください。頼んだら、あとは待つだけです。
