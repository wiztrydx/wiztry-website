「問い合わせの管理表を作りたいけれど、Excel の関数は詳しい社員に任せきり」「会議でホワイトボードに書いた段取りは、写真を撮って終わり」。そんな会社は多いと思います。

Anthropic が11月10日（米国時間。日本では11月11日の未明）に発表した Claude Sheets と Claude Whiteboards は、ここに効く新機能です。一言で言うと、Claude が「答えを返すAI」から、「表も図も資料も、その中で作って仕上げるAI」になりました。

この記事は、11月13日に公開した YouTube 動画の内容を、録画の記録と公式の情報に照らして書き直したものです。実際に試した画面を、社長の目線で「仕事のどこで使えるか」まで整理しました。動画で使った頼み方も、そのまま載せています。

## この記事の要点

- Claude Sheets は、Claude の中で作る表です。問い合わせのメモを貼って頼むだけで、プルダウンと集計のタブがついた管理表ができました。合計はAIが考えた数字ではなく、セルの計算式が出しています
- Claude Whiteboards は、話した段取りを箱と矢印の図にするホワイトボードです。抜けを聞くと、まず文章で答え、「ボードに足して」と頼むと図に足しました。ボードは、そのまま計画書とスライドにできます
- 今の Sheets は、公式も「シンプルなスプレッドシート機能」と書いています。ピボットテーブルやマクロは使えないので、Excel をやめるのではなく、新しく作る軽い表から試すのがおすすめです
- どちらもベータ版で、有料プラン（Pro・Max・Ultra・Team・Enterprise）だけです。動画の公開後に、Sheets の「まだ無い機能」の一覧とスマホの扱いが変わりました

## まず全体像：Claude の中に、表とホワイトボードが加わった

順番に説明する前に、全体を先に出します。

Claude には前から、Word にあたる Docs と、PowerPoint にあたる Slides がありました。今回、Excel にあたる Sheets と、ホワイトボードの Whiteboards が加わりました。文書、スライド、表、図が、Claude の中でそろったことになります。

![表も図も資料もClaudeの中で。新しく加わったSheetsとWhiteboards、前からあるDocsとSlides](/blog/claude-sheets-whiteboards/diagram-1-overview.webp)

この記事では、次の3つを順に説明します。

1. Claude Sheets：Claude の中で、Excel のような表を作る・直す・書き出す
2. Claude Whiteboards：話した段取りを図にして、そのまま計画書やスライドにする
3. Excel の代わりになるのか：できないことと、使えるプラン

どれも Claude の「アーティファクト」という仕組みの上で動きます。アーティファクトは、チャットの横に開く作業用の画面のことです。作った物は、Claude の「Artifacts」のタブにたまっていきます。

同じ日に、10月にベータ版で出ていた Claude Dashboards が、Claude Data という名前で正式版になりました。社内のデータベースや業務のアプリとつないで、ふだんの言葉で質問すると、ダッシュボードなどを作る機能です。つなぐ準備が要る話なので、この記事では扱いません。

先に2つ、条件をお伝えします。

1点目。録画は11月12日に、有料プランの Claude で撮りました。モデルは Fable 5.2 です。ベータ版なので、画面や動きは変わることがあります。

2点目。この記事に出てくる会社、お客様、金額は、すべて架空です。「みどり工務店」も、問い合わせのメモも、キャンペーンも実在しません。

## 1つ目：Claude Sheets

Claude Sheets は、Claude の画面の中で作る表です。Excel のように、タブ、計算式、プルダウン、色付け、グラフが使えます。

今までも、Claude に Excel のファイルを作らせることはできました。ただ、直してもらうたびに、ダウンロードして開き直す必要がありました。新しいのは、同じ表を、自分と Claude の両方がその場で直せることです。Claude が直した所には印が付くので、どこが変わったかも分かります。

### 実演1：問い合わせのメモ5件から、管理表を作る

題材は、架空のリフォーム会社に届いた問い合わせのメモ5件です。受付日、名前、受付の経路、相談の中身が、ばらばらの文で書いてあります。これを貼って、こう頼みました。

> この5件の問い合わせメモから、問い合わせの管理表を作って。状況はプルダウンで選べるようにして、別のタブに、状況ごとの件数と見積金額の合計を出して。

![Claude Sheetsの実演。メモ5件を貼って頼むと、管理表と、状況のプルダウンと、状況ごとの件数と金額の合計のタブができた](/blog/claude-sheets-whiteboards/sheets-steps.webp)

できた表は次のとおりです。

- 「問い合わせ一覧」のタブに、受付日・お名前・状況・見積金額・受付経路・内容・希望の列
- 状況は「未対応・連絡済み・現地調査済み・見積提出済み・成約」の5つから、プルダウンで選ぶ
- 見積金額は、メモに金額が無いので「要確認」
- 別のタブに、状況ごとの件数と見積金額の合計

ここで2つ、見ておきたい所があります。

1つ目は、頼み方に「5つの状況」を書いていないことです。状況の選び方は、Claude が考えたものです。リフォーム会社の流れとしては自然ですが、自社の呼び方や段階と合っているかは、担当の人が見て直してください。

2つ目は、メモに無い金額を、Claude が勝手に埋めなかったことです。「要確認」と入れて、空いている所が分かるようにしてくれました。

### 集計は、セルの計算式が出している

次に、1件目の状況をプルダウンで「見積提出済み」に変えて、金額に 1,850,000 を入れました。すると、集計のタブの数字がすぐに変わりました。

![計算式と書き出しと色付け。合計のセルを選ぶとSUMIFSの式が見える。書き出しはExcelとCSV。未対応の4行に色が付いた](/blog/claude-sheets-whiteboards/sheets-formula.webp)

ここが一番大事なところです。この合計は、AIが考えて入れた数字ではありません。セルに入った計算式が出しています。合計のセルを選ぶと、上の欄に式が出ます。

`=SUMIFS(問い合わせ一覧!E2:E,問い合わせ一覧!D2:D,A5)`

SUMIFS（サムイフス）は、条件に合う行の数字だけを足す関数です。この式は、「問い合わせ一覧のタブで、状況が『見積提出済み』の行だけ、見積金額を足す」という意味です。いちばん下の合計の行は、SUM で縦に足しています。

AIに計算を任せると、合っているか不安になります。式が残っていれば、どう計算したかを自分の目で確かめられます。公式のヘルプにも、数式はセルに残るので、それぞれの数字がどう計算されたかを確認できる、と書かれています。

### 実演2：表を見ながら、追加で頼む

表を見ながら、もう一言だけ頼みました。

> 受付から3日たっても未対応の行に、色を付けて。

5件のうち、見積提出済みの1件目を除く4行に、薄い赤の色が付きました。放っておいた問い合わせが、一目で分かります。

<img src="/blog/claude-sheets-whiteboards/color-chat.webp" alt="色付けを頼んだときのClaudeの返事。土日も1日と数えること、200行目まで設定したこと、Excelに書き出すと色付けのルールは引き継がれないことが書いてある" width="560" height="804" loading="lazy" style="display:block;width:100%;max-width:560px;height:auto;margin:1.5em auto;border-radius:8px;">

Claude の返事には、自分で決めたことが書いてありました。

- 状況を「未対応」以外に変えると色が消え、新しく足した行も3日たつと色が付く（200行目まで設定）
- 日数は、土日・祝日も1日と数える。営業日で数えたいなら言ってほしい
- Excel に書き出した .xlsx には、この色付けのルールは引き継がれない

「3日」を土日込みで数えるか、営業日で数えるか。人に頼むときも、決めておかないとずれる所です。Claude はそこを自分で決めて、決めたことを書いてくれました。なので、返事は最後まで読んでください。社内の決まりと違えば、言い直せば直ります。

最後の1つは、表を Excel に書き出して使う会社には大事な注意です。今回はファイルを開いて確かめていないので、Claude の説明として書いておきます。

### 直した所が分かり、前の版にも戻せる

Claude が直したセルには、茶色の枠と「Claude」の札が付きます（上の図の③）。もし違っていたら、版の履歴から前の版に戻せます。公式のヘルプによると、前の版に戻すと、その後に加えた編集も消えます。

もちろん、セルに自分で数字を打って直すこともできます。録画でも、金額を自分で打ち込んで書き換えました。Claude と自分が、同じ表を同じように触れる。これが Sheets の一番の特徴です。

Excel の関数が苦手で、表作りを詳しい社員に任せきりの会社には、かなり便利だと思います。

### 書き出しと取り込み

- 書き出し：Excel（編集できる .xlsx）と CSV。送信先として Google スプレッドシートも出ました
- 取り込み：CSV、Google スプレッドシート、Excel から取り込めます。Excel や Google スプレッドシートからの貼り付けもできます（公式のヘルプ）
- ほかのツールへ：公式の発表では、Airtable、Asana、monday.com、Smartsheet で作業を続けられるとしています

録画に使ったブラウザはダウンロードを止めていたので、書き出しはメニューを開いて見せるところまでです。取り込みも、入力欄の「＋」のメニューを見せたところまでで、実際のファイルでは試していません。

### 共有と、チャット以外からの作り方

表は、最初は自分だけが見られる状態で作られます（画面には「あなたのみ」と出ます）。共有で「編集可能」にした相手は、自分と Claude と一緒に、同じ表で作業できます。

作り方は、チャットで頼むほかに、Artifacts のタブの「Sheets」から始めることもできます。動画で話した Claude Code（Claude の開発者向けの画面）からも頼めると、公式のヘルプに書かれています。撮影の前の試しで作れることは確かめましたが、動画には映していません。

### Sheets の頼み方のコツ

今回の結果と公式のヘルプから、コツを4つにまとめます。

1. 元のデータを渡す：公式も、数字があるなら渡すよう書いています。メモや CSV をそのまま貼れば十分です
2. 欲しい形を言う：「プルダウンで」「別のタブに」「状況ごとの件数と合計」のように、選び方と置き場所を言うと、その形で出ます
3. 決まりは言葉で書く：「3日」の数え方のように、社内で決まりがある物は先に書きます
4. 式を見る：合計や集計は、セルを選んで式を確かめます

## 2つ目：Claude Whiteboards

Claude Whiteboards は、話した内容を箱と矢印の図にするホワイトボードです。

今までは、頭の中の段取りを Claude に話しても、返ってくるのは文章でした。新しいのは、箱と矢印の図で返ってきて、その箱を自分でも動かせることです。共有すれば、ほかの社員と同じボードに一緒に書き込めます。

### 実演1：思いつくままの段取りを、ボードにする

題材は、架空の工務店の「冬のお風呂リフォームのキャンペーン」です。段取りを思いつくままに並べて、こう頼みました。

> 冬のお風呂リフォームのキャンペーンの段取りを、ホワイトボードにして。期間は、11月20日から12月25日。始まる前に、チラシを作って、ホームページに載せて、以前のお客様に案内を送る。期間中は、問い合わせを受けて、現地調査に行って、見積もりを出して、契約する。終わったら、申し込みの数と売上を振り返る。

![Claude Whiteboardsの実演。思いつくままの段取りが3つの段階のボードになり、抜けを聞くとまず文章で答え、足してと頼むと箱が増えた](/blog/claude-sheets-whiteboards/whiteboard-steps.webp)

できたボードは、「準備→受付から契約→振り返り、の3段階で進める」という見出しで、「始まる前」「期間中」「終わったら」の3つの段に分かれていました。段の名前には期間の日付も入り、8つの作業が矢印でつながっています。思いつくまま話しただけで、順番まで組んでくれました。

注目したいのは、ボードの下の小さな赤い字です。「要確認：各作業の担当者と期日」。頼み方に担当者と期日は無かったので、Claude はそこを勝手に埋めず、決まっていないと書きました。

公式の発表は、担当者や期限を含むタイムライン付きのボードにまとめる、と説明しています。ただ、話した中に無い物は空欄のまま残る、と考えておくとよいと思います。

ボードを作ったあと、Claude は「以前のお客様への案内は、いつまでに送り終えたいですか？」と聞いてきました。今回は答えずに、次へ進んでいます。

### 実演2：抜けを聞くと、まず文章で答えた

次に、抜けがないかを聞きました。

> この段取りで、抜けているところはありますか？

Claude はまず、チャットに文章で答えました。最初の1行は「はい、いくつかあります。ボードは変えていません。」です。

始まる前・期間中・終わったあと、に分けて、キャンペーンの内容を決める、チラシを配る、受付の準備、問い合わせの記録、見積もりのあとのフォロー、締切の扱い、契約のあとの工事、などが挙がりました。ボードの上には、抜けている点を4つにまとめた吹き出しが出ました。

そこで、もう一言頼みました。

> 抜けている段取りを、ボードに足して。

すると、ボードの右上に「最初に決めること」の枠ができて、「予算と目標件数を決める」「担当者と期日を決める（チラシ・案内の締切も）」の2つの箱が入りました。終わったあとの段には、振り返りの前に「工事・引き渡し」の箱が足されています。契約で終わらず、工事まで見ないといけない、ということです。

ポイントは、聞くだけではボードの箱は変わらず、「足して」と頼むと変わる、という所です。勝手に書き換えないので、社員と一緒に使うときは安心な動きです。逆を返せば、図に入れてほしいときは、そう言葉にする必要があります。

公式のヘルプには、抜けを聞くと Claude が提案をボードに追加する、と書かれています。今回の録画では、提案はまず吹き出しとしてボードに出て、箱が増えたのは「足して」と頼んだあとでした。

### 実演3：ボードを、そのまま計画書とスライドにする

ここからが、私が一番便利だと思う所です。

> このボードを、社員に配る計画書にして。

![ボードから計画書とスライドへ。計画書はWord・PDF・Markdownで、7枚のスライドはPowerPointやPDFで書き出せる](/blog/claude-sheets-whiteboards/board-to-docs.webp)

ボードの中身が、そのまま文書になりました。概要、最初に決めること、始まる前……と、ボードの段の順に見出しが並びます。ここでも、担当者・期日・予算・目標件数は「要確認」のままで、Claude は「予算はいくらですか？」と聞いてきました。

文書の書き出しは、Word（編集できる .docx）、PDF、Markdown の3つで、Google ドキュメントと Notion へ送るメニューもありました。

> このホワイトボードを、スライドにして。

7枚のスライドができました。表紙、全体の流れ、最初に決めること、始まる前、期間中……と続きます。書き出しは、PDF、Web ページ（.html）、今のスライドの画像（.png）、PowerPoint（.pptx）です。PowerPoint は、今のフォントのままの物と、どのパソコンでも崩れにくい基本のフォントの物の、2つから選べました。

会議でホワイトボードに書いて、写真を撮って終わり、という会社は多いと思います。その中身がそのまま計画書やスライドになるので、会議のやり方が変わる会社も出てきそうです。

### 動画で映していない所を、公式のヘルプで補う

- マイク：送信ボタンの横のマイクで話すと、文字になって入力欄に入ります。日本語にも対応しています
- 一部だけ聞く：ボードの一部をドラッグで囲んで、その部分だけを Claude に聞けます
- 一緒に作業する：ボードにいる人は、だれでも箱を動かせます。社外の人は、メールで招待すれば参加できます（Team と Enterprise は、管理者の設定が必要です）
- ほかのツールへ：Lucid、Miro、Zoho Vani に送れます。PNG の画像でも書き出せます
- できないこと：ファイルからボードを取り込むことはできません。つないだアプリの情報も使いません。ボードの上にある物だけで考えます

### Whiteboards の頼み方のコツ

1. 段の区切りを言う：「始まる前に」「期間中は」「終わったら」と区切って話すと、その段のとおりに図になりました
2. 日付を入れる：期間を言うと、段の名前に日付が入りました
3. 抜けを聞いてから足す：聞くと文章で答え、「ボードに足して」で図に入ります。足す物を人が選べます
4. 渡す相手を言う：「社員に配る計画書にして」のように、だれに渡す物かを言います

## 3つ目：Excel の代わりになるのか

結論から言うと、現時点では、Excel の代わりにはならないと私は思います。

![Excelの代わりになるか。新しく作る軽い表はSheetsで、大きなファイルやマクロ入りの表はExcelのまま。ピボットテーブルはまだ無く、マクロは対応しない](/blog/claude-sheets-whiteboards/diagram-2-excel-or-sheets.webp)

公式の発表にも、「現時点では、Sheets はシンプルなスプレッドシート機能を提供」と書かれています。Excel のすべての機能が必要なら、.xlsx か CSV に書き出すか、Claude for Excel を使うよう案内しています。

11月21日時点の公式のヘルプでは、次のとおりです。

| 区分 | 中身 |
|---|---|
| まだ無い | ピボットテーブル、保護された範囲、共有フィルタービュー、複数選択のプルダウン、PDF での書き出し |
| 対応しない | マクロ、VBA、Power Query、DAX、印刷レイアウト |
| 大きさ | 入力済みのセルで、少なくとも20万個を扱える |
| グラフ | 棒グラフ、折れ線グラフ、円グラフなど |
| つないだアプリ | 最新のデータを取ってくることはできない |

ピボットテーブルは、大きな表を項目ごとに集計し直す Excel の機能です。マクロと VBA は、Excel の作業を自動で動かす仕組みです。どちらも、長く使っている会社の表には入っていることが多いと思います。

なので、使い分けはこうなります。

| 表 | どちらで | 理由 |
|---|---|---|
| 新しく作る管理表 | Sheets | Claude と一緒に作って直せる |
| 小さな予算表 | Sheets | 式を見て確かめられる |
| 長年使ってきた大きなファイル | Excel | 中身と書式をそのまま守れる |
| マクロ・VBA が入った表 | Excel | Sheets は対応していない |
| 印刷して配る帳票 | Excel | 印刷レイアウトが無い |
| ピボットテーブルで集計する表 | Excel | まだ無い |

Excel をやめるのではなく、新しく作る表から Sheets で試すのがおすすめです。今ある Excel のファイルのまま Claude を使いたいなら、Claude for Excel という別の道もあります。

## 使えるプランと注意点

![使えるプランと注意点。有料プランだけ、無料プランは不可、Enterpriseは管理者がオンにしてから、使った分はふだんのチャットと同じ上限に数える](/blog/claude-sheets-whiteboards/diagram-3-plans.webp)

- どちらもベータ版です
- 使えるのは有料プランの Pro、Max、Ultra、Team、Enterprise です。無料プランでは使えません。Docs と Slides は、無料プランでも使えます
- Team は最初からオンです。Enterprise は、管理者が組織の設定の「Artifacts」でオンにするまで使えません
- 使った分は、ふだんのチャットと同じ使用量の上限に数えます
- 使える場所：Sheets はウェブとデスクトップのアプリで、スマホは「アクセスは制限付き」とだけ書かれています。Whiteboards は、ウェブ、デスクトップ、スマホで使えます
- データの管理：Sheets は、ベータ版のため HIPAA（米国の医療情報の決まり）と ZDR（データを残さない契約）にまだ対応していません。Whiteboards は、HIPAA に対応した構成の組織では使えません

画面に出てこないときは、設定の「機能」で、ファイルの作成と編集（英語の画面では Create and edit files）がオンになっているかを確かめてください。公式のヘルプでは、アーティファクトを使うにはこの設定が必要と書かれています。

料金は変わることがあるので、[公式の料金ページ](https://claude.com/pricing)で確かめてください。

## 動画の補足：正確にはこうです

動画の中で話した言葉のうち、知っておいてほしい3点です。記事はこちらを正としています。

1点目。2:59ごろの「今回は文字を打たずに、いつも通りマイクで話してみます」は、録画では同じ文を打ち込んでいます。打った文は、話した言葉と同じ内容です。マイクのボタンは送信ボタンの横にあり、日本語の音声入力にも対応しています（公式のヘルプ）。

2点目。3:30〜3:38ごろの「抜けを聞くと、足りない段取りをボードの上に足してくれました」は、実際には2段階です。抜けを聞くと、Claude はまず文章で答え、「ボードは変えていません」と書きました。そのあと「抜けている段取りを、ボードに足して。」と頼んで、箱が足されました。

3点目。4:41ごろの「順番に提供が始まっているので、有料プランでもまだ画面に出てこない方がいます」は、11月21日時点のヘルプにはその書き方がありません。出てこないときは、プランと、設定の「ファイルの作成と編集」と、Enterprise なら管理者の設定を確かめてください。

## 仕事のどこで使えるか

ここからは、社長の目線で整理します。今回の新機能をひとまとめにすると、頭の中やメモにある物を、その場で形にして、みんなで直せるようになった、というところです。

![明日から使える場面。問い合わせの管理表、会議の段取り、キャンペーンの計画、社内の説明資料、小さな予算表、抜けの確認](/blog/claude-sheets-whiteboards/diagram-4-uses.webp)

| 場面 | 使う機能 | 頼み方の例 | 見る所 |
|---|---|---|---|
| 問い合わせの管理 | Sheets | メモを貼って「管理表にして」 | 状況の選び方が自社と合うか |
| 小さな予算表 | Sheets | 「項目ごとの予算表を作って」 | 合計の式 |
| 会議の段取り | Whiteboards | 話した内容を「ボードにして」 | 担当者と期日 |
| キャンペーンの計画 | Whiteboards から Docs | 「社員に配る計画書にして」 | 「要確認」の所 |
| 社内の説明資料 | Whiteboards から Slides | 「スライドにして」 | 数字と日付 |
| 抜けの確認 | Whiteboards | 「抜けているところは？」 | 足すかは人が決める |

たとえば会議なら、話しながらボードを作って、終わったら計画書にして配る。写真を撮って、だれかが清書する手間が丸ごと無くなります。

Google のサービスを中心に使っている会社は、請求書やスライド作りを Gemini に任せて試した [Geminiの「タスク」の記事](/blog/gemini-tasks-muryou/) も参考にしてください。

### 社内で使うなら、先に決めておく3つ

会社で回すなら、難しいルールは要りません。先にこの3つだけ決めておくのがおすすめです。

1. どの表から始めるか：新しく作る表、社内だけで使う表から始めます。お客様に出す数字は、式を確かめてからにします
2. 何を入れないか：お客様の個人情報や取引先の名前は、最初は伏せるか、架空のデータで試します
3. 決めごとをだれが入れるか：Claude が「要確認」と残した担当者・期日・予算は、人が決めて入れます

## よくある質問

### 無料プランでも使えますか

Sheets と Whiteboards は使えません。有料プランの Pro、Max、Ultra、Team、Enterprise だけです。前からある Docs と Slides は、無料プランでも使えます。

### 会社のデータを入れても大丈夫ですか

学習への利用は、プランで扱いが違います。公式のプライバシーの案内では、個人向けのプラン（Free・Pro・Max など）は、Claude の改善に使うことを自分で許可した場合などに使われます。法人向け（Team・Enterprise など）は、初期の設定では学習に使わないと書かれています。どちらも、評価のボタン（グッド・バッド）で送った会話などは別の扱いです。

いずれにしても、ベータ版の今は、個人情報を入れる前に社内の決まりを確かめ、まずは架空のデータか、名前を伏せたデータで試すのがおすすめです。

### 今ある Excel のファイルを直せますか

Excel から取り込んで、続きを頼むことはできます（公式のヘルプ）。ただ、マクロ、VBA、Power Query、印刷レイアウトは対応していません。ファイルを Excel のまま使いたいときは、Claude for Excel が公式の案内です。

### 大きな表も扱えますか

11月21日時点の公式のヘルプには、入力済みのセルで少なくとも20万個を扱えると書かれています。10列の表なら、2万行ほどが目安です。上限がいくつかは書かれていません。

### 社員と一緒に直せますか

表は、最初は自分だけが見られる状態で作られます。共有で「編集可能」にした相手は、自分と Claude と一緒に、同じ表で作業できます。Whiteboards も、ボードにいる人はだれでも箱を動かせます。

### スマホでも使えますか

Whiteboards は、スマホのアプリでも使えます。Sheets はウェブとデスクトップが対象で、スマホは「アクセスは制限付き」と書かれています（11月21日時点）。何ができるかまでは書かれていないので、表を作る・直す作業はパソコンでするのが確実です。

### AIが作った計算は信じてよいですか

今回の合計はセルの計算式が出していて、式は選べば見られます。ただ、どの列を足すかといった式の中身は Claude が決めています。お客様に出す数字や経営の判断に使う数字は、一度、手計算か Excel で突き合わせてください。

### Claude Code からも作れますか

公式のヘルプでは、Claude Code の中でもアーティファクトを頼めます。撮影の前の試しで作れることは確かめましたが、動画では映していません。

### 画面に出てこないときは

次の順に確かめてください。

1. 有料プランか
2. 設定の「機能」で、ファイルの作成と編集がオンか
3. Team と Enterprise なら、管理者の設定でオンになっているか

## 始め方3ステップ

1. 今日：手元の問い合わせのメモを、名前を伏せて貼り、「問い合わせの管理表にして」と頼む
2. 明日の会議で：決めたい段取りを話して「ホワイトボードにして」と頼み、「抜けているところはありますか？」と聞く
3. 今週中に：できたボードを「社員に配る計画書にして」と頼み、「要確認」の所を人が埋めて配る

最初はちょっと試すくらいで大丈夫です。上の頼み方の文字を、自社の物に置き換えて使ってください。

あなたの会社なら、どちらを先に使ってみたいか。まずは、毎回作り直している表か、写真を撮って終わっている会議を1つ、思い浮かべてみてください。
